# 日常本 DailyBook · 集中タイマー FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

Kotlin + Jetpack Compose で作られた**完全オフライン**の Android アプリです。
**インターネット権限はありません — データが端末の外に出ることはありません。**

---

## アプリの紹介

**日常本（DailyBook）**は、家計簿・ToDo・ポモドーロタイマーを 1 つのアプリにまとめたものです。
下部の 5 つのタブ：**家計簿 · ToDo · 集中 · 統計 · 設定**。

| タブ | できること |
| --- | --- |
| 📒 **家計簿** | 収入・支出、既定のカテゴリ、メモ、日付選択、日付ごとにまとめた月間の明細、月の切り替え、カテゴリ別の割合、日別支出の棒グラフ、**月間予算の進捗バー**、**検索**、**記録をタップしてそのまま編集**、**CSV 書き出し（Excel で文字化けしません）** |
| ✅ **ToDo** | すばやい追加、完了チェック、重要マーク、期限と期限切れの表示、**繰り返しタスク（毎日 / 毎週 / 毎月、完了すると次回分を自動作成）**、**期限日のお知らせ通知**、状態フィルター、**検索**、完了済みをまとめて削除 |
| ⏱️ **集中** | ポモドーロタイマー：集中 / 短い休憩 / 長い休憩、グラデーション付きリング進捗、フェーズ終了時に通知 + 振動、次のフェーズへ自動移行も可能、N 個ごとに長い休憩、**今日のセッション一覧** |
| 📊 **統計** | 今日のポモドーロ数、連続日数、直近 7 日のグラフ、家計簿の集計、**直近 12 か月の収支トレンド**、**年間サマリー**（年間支出 / 年間収入 / 年間収支、件数、いちばん使ったカテゴリ）、**累計の収支と純残高** |
| ⚙️ **設定** | 各フェーズの長さ、振動、画面常時点灯、テーマ、**バックアップと復元**、**CSV 書き出し**、データの削除 |

さらに：色と絵文字付きのカテゴリバッジ、タブレット / 横向きのサイドナビゲーション。

**バックアップと復元**：すべてのデータ（家計簿、ToDo、集中セッション、月間予算）を
1 つの JSON ファイルに書き出し、あとからまとめて復元できます。ファイルはシステムの
ファイル選択画面で指定した場所に保存されるため、**ストレージ権限は引き続き不要**です。
復元は現在のデータを置き換えるので、実行前に確認ダイアログが表示されます。

**FocusFlow（集中タイマー）**は以前の単体ポモドーロアプリです。
タイマーだけが欲しい方のために残しています。

## インストール要件

| 項目 | 要件 |
| --- | --- |
| **対応 OS** | **Android 8.0（API 26）以上**。ビルドターゲットは Android 15（API 35） |
| **APK サイズ** | 約 1.6 MB |
| **インストール方法** | 自己署名のため（ストア配信ではありません）、端末の設定で「提供元不明のアプリ」を許可する必要があります |
| **要求する権限** | 通知・振動・再起動後の ToDo リマインダー再設定の 3 つのみ。**ストレージ権限は不要**：バックアップと CSV はシステムのファイル選択画面を経由します |
| **ネットワーク** | **インターネット権限は一切ありません。** どこにも送信しません |
| **データの保存先** | 端末内のみ。アンインストールすると削除されます。**上書き更新ではデータは失われません**（データベースは自動移行、現在はバージョン 3） |
| **アップデート** | 全バージョンでパッケージ名と署名が同一のため、新しい APK をそのまま上書きインストールできます。更新時はデータベースが自動で移行し、既存の家計簿・ToDo・集中セッションの記録はそのまま残ります |
| **既知の制限** | 署名されているのは正式版のみで、デバッグ版は署名が異なるため正式版に上書きインストールできません。計測中にシステムがバックグラウンドでアプリを終了すると、タイマーは中断します。ToDo のリマインダーは非正確アラーム（正確なアラーム権限は要求しません）のため、9:00 の通知が数分遅れることがあります |
