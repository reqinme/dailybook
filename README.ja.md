# 日常本 DailyBook · 集中タイマー FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

Kotlin + Jetpack Compose で作られた**完全オフライン**の Android アプリです。
**インターネット権限はありません — データが端末の外に出ることはありません。**

---

## アプリの紹介

**日常本（DailyBook）**は、家計簿・生活・学習・ToDo・ポモドーロタイマーという 5 つの道具を 1 つのアプリにまとめたものです。
下部の 5 つのタブ：**家計簿 · 生活 · 学習 · 集中 · 統計**。設定はタブから上部の細いバーの歯車アイコンへ移り、下位ページではそのバーの左側に戻る矢印が出ます。

さらに：色と絵文字付きのカテゴリバッジ、**ランチャーのショートカット（アプリアイコンを長押しすると、記録の追加 / ToDo の追加 / 集中の開始へ直接移動）**、タブレット / 横向きのサイドナビゲーション。

**ホーム画面ウィジェット**：1 つめは今日の支出と収入、残っている ToDo の件数、今日の集中時間を表示し、タップするとアプリが開きます。2 つめは**試験のカウントダウン**で、ある試験の名前・日付・残り日数（N 日 / 今日 / 終了済み）に加えてコース名と場所を表示し、小さな「切替」ホットスポットで今後の試験を順に切り替えられます（選んだ試験はそのウィジェットインスタンスごとに記憶されます）。今後の試験が無いときはやさしい案内を出します。どちらもフレームワーク標準の `RemoteViews`（Glance ではありません）で作られており、アプリのデータが変わったときに更新し、それ以外はシステムが許す最小間隔である 30 分ごとに更新します。文字は**システム**の言語に従い、システムがアプリ内で選んだ言語を認識できる場合はアプリ内の言語を使います。

**生活は 1 つのタブに**：生活タブはセグメントコントロールで ToDo・習慣チェックイン・メモ・大事記・重要日付を切り替えます。習慣は 1 行で、絵文字・名前・単位付きの 1 日の目標・現在の連続日数・今週の日数・7 日間のミニグリッドを持ち、+/− か行のタップで記録します。週目標は進捗（例：今週 2 / 3 日）と達成の表示が付きました。**単語や暗唱の計画は別機能ではなく、単位と 1 日の目標を持たせた習慣そのもので、「習慣チェックイン」で管理します**。メモは 2 列のカード。大事記は年ごとのタイムライン。重要日付は直近の 1 件をカウントダウンカードで示し、新暦と**旧暦**（閏月を含む）、繰り返しルール、リマインダー（書き出す .ics に影響するだけでなく、アプリ内通知を本当に出すようになりました）、項目ごとの **.ics 書き出し**に対応しているので、スマートフォンのカレンダーに取り込めます。「只过一次」の日付は過ぎたあとも消えず、「已经过去」グループに移って「已过去 N 天」と表示されます。

**学習も 1 つのタブに**：学習タブはハブです——サマリーカード、今日の授業、そして 8 つの下位ページ（時間割・試験と復習・課題と DDL・成績と GPA・単位数の進捗・奨学金と資格・学習ウィークリーレポート・単語の計画）。時間割は 7 × 12 の週グリッドで、本物の表として描かれています——時限と曜日のあいだに罫線、ヘッダーの下に区切り線、左端の時限の列もグリッドと揃います。曜日のヘッダーとグリッドは同じ横スクロール状態を共有するので、横にスクロールしても曜日のラベルが違う列の上に来ることはありません。ブロックは時限の範囲で高さが決まりコースごとに色が付き、`1-16` や `1-16单` のような週次表現で動きます。課題は ToDo のうちコース名が付いたものを絞り込んだ一覧で、期限切れ / 今日 / 今週 / それ以降 / 日付なし / 完了 に分かれ、期限切れの行は強調されます——別のリストではなく同じ行です。試験を展開すると復習タスクの一覧が出て、均等な間隔の復習案を出すボタンもあります（消してかまいません）。成績は百分制 / 五段階評価を GPA 値に換算し、ウィークリーレポートは直近 7 日をまとめて PNG として書き出せます。

**このアプリについてと更新**：このアプリについてページは、アプリ名・パッケージ名・バージョン・最低 Android バージョンをハードコードせず実行時にインストール済みパッケージから読み取り、データはすべて端末内にあると明記しています。**更新の確認**は現在のバージョンを示して GitHub のリリースページをブラウザで開くだけです——インターネット権限が無いのでアプリ内での更新確認はできず、ページにはそのとおり書いてあります。このアプリについてページ自身にも更新の確認の行はもうありません：設定 ▸ このアプリと更新 の入口と重複していたので行ごと外しました。

**12 種類の配色**：青 / インディゴ / バイオレット / ローズ / アンバー / フォレスト / スカイ / ミント / コーラル / コーヒー / グラファイト / サクラで、それぞれライトとダークの 2 版があります。コントラストは目視ではなく計算で確認しています——単体テストが両モードで本文 4.5:1 以上、UI 要素 3:1 以上を検証し、12 個の主色が互いに異なることも確かめるので、配線を間違えた配色が気づかれずに出荷されることはありません。**カスタム背景画像**も設定できます：システムのファイル選択画面で画像を 1 枚選ぶと各面が半透明になり、マスクのスライダー（0~80）が画像の透け具合を決め、「消去」ボタンで外せます。

**4 つの言語**：すべての画面・通知・書き出す CSV が **简体中文 / 繁體中文 / English / 日本語** に対応しています。
「設定 → 言語」で切り替えると**すぐに反映され、再起動は不要**です。ランチャーのアプリ名と
長押しショートカットの名前は**システム**の言語に従います（システム側の UI のため）。

**バックアップと復元**：すべてのデータ（アカウント・タグ・通貨・精算状態を含む家計簿、サブタスクのチェックリスト・優先度・手動の並び順・コース名を含む ToDo（コース名・優先度・手動の並び順はいま書き出して復元してもそのまま残ります——以前はバックアップから戻すと ToDo のコース名が失われ、作業 / DDL のコースの紐づけが消えていました）、
定期的な記録のルール、集中セッション、月間予算とカテゴリ予算、さらに生活の記録——メモ・大事記・重要日付・習慣とそのチェックイン記録——と学習の記録——コース・試験と復習タスク・成績・単位の目標・奨学金と資格）を 1 つの JSON ファイルに書き出し、あとからまとめて復元できます。ファイルはシステムの
ファイル選択画面で指定した場所に保存されるため、**ストレージ権限は引き続き不要**です。
復元は現在のデータを置き換えるので、実行前に確認ダイアログが表示されます。確認の文面は、実際に触るモジュールをひとつずつ明記するようになりました（復元は 16 個のテーブルすべてを消去します）——以前のように「家計簿 / ToDo / 集中」だけを挙げることはありません。「全データを消去」と「完了済み ToDo をすべて削除」も同じ方針で書き、バックアップの説明には含まれるモジュールをすべて列挙しています。
古いバージョンが書き出したバックアップもそのまま復元できます——v2〜v4 の古いファイルも読み込み、無いセクションは空のまま、
含まれていない項目は既定値で補われます（タグは空、精算待ちではない、人民元のレートは 10000、優先度は「ふつう」、サブタスクなし）。

**自動バックアップ**：**システムのファイル選択画面**でフォルダーを 1 つ選びます（**ストレージ権限は引き続き不要**）。アプリを開いたとき、または夜のリマインダーのときに、全データを 1 つの JSON ファイルとして書き出します。**1 日につき最大 1 ファイル**（同じ日は上書きするので、`…… (1).json` のような複製はできません）で、**最新 7 件だけを残し**、古いものは自動で片付けます。片付けるときに削除するのは**自分が作ったファイル**（`DailyBook-backup-` で始まるもの）だけで、同じフォルダーに置いた他のものには一切触れません。失敗したときは原因（権限がない / 作成できない / 書き込めない）を正直に伝え、成功を装うことはありません：**失敗が「前回の成功」の記録を上書きすることも、成功として表示されることもありません**。

**人民元ひとつの基準**：外貨で記録しても、保存されるのは換算後の人民元額です（元の金額も保持され、一覧に表示されます）。
そのため**統計・予算・レポートはすべて人民元という 1 つの基準に揃います**。取り込みも同じ方針で、
**CSV を取り込むとき、既存の記録と完全に同じ行（日付・金額・種類・カテゴリ・アカウント・メモがすべて一致）はスキップされます**。
同じファイルを 2 回取り込んでも重複しません。読み取れない行は無視され、取り込み全体が失敗することはありません。

**固定費は自動で記録**：定期的な記録は、**アプリを開いたとき**（または夜のリマインダーの時刻）に補われ、補うたびにそのルールの次の期日が先へ進みます。だから**記録漏れも二重記録もありません**。長く開かなかった場合も直近の 1 回分だけを補い、間の期日をまとめて書き込むことはありません。

**月報の書き出し**：統計ページから、今月を**共有できる PNG 画像**、**単体で開ける HTML ファイル**（インライン CSS のみ。スクリプトも外部リソースも無いので、オフラインでもそのまま読めます）、**PDF**（A4、必要に応じて複数ページ）として書き出せます。3 つともシステムのファイル選択画面を経由するので、**ストレージ権限は引き続き不要**です。レポートにはその月の数字、棒グラフ、カテゴリの内訳、集中の統計、インサイトの文が入り、その月にデータが無いときは空のファイルを書かず、書き出せるものが無いと伝えます。

**FocusFlow（集中タイマー）**は以前の単体ポモドーロアプリです。
タイマーだけが欲しい方のために残しています。

| **APK サイズ** | 約 2 MB |
| **インストール方法** | 自己署名のため（ストア配信ではありません）、端末の設定で「提供元不明のアプリ」を許可する必要があります |
| **要求する権限** | 通知・振動・再起動後のリマインダー再設定（ToDo・毎晩の記帳リマインダー・定期のまとめ）の 3 つのみ。**ストレージ権限は不要**：バックアップ・CSV・月報・.ics の書き出し・週報の PNG はシステムのファイル選択画面を経由します。**v1.10 で権限は 1 つも増えていません**：重要日付の事前リマインダーは同じ非正確アラーム（専用の通知チャンネル、現地時間 9:00）を使い、時間割の表・組み直される授業リマインダー・この新しい通知はいずれもフレームワークの標準 API です。更新の確認はブラウザを開くだけです |
