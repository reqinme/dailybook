# 日常本 DailyBook · 集中タイマー FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

Kotlin + Jetpack Compose で作られた**完全オフライン**の Android アプリです。
**インターネット権限はありません — データが端末の外に出ることはありません。**

---

## アプリの紹介

**日常本（DailyBook）**は、家計簿・ToDo・ポモドーロタイマーを 1 つのアプリにまとめたものです。
下部の 5 つのタブ：**家計簿 · ToDo · 集中 · 統計 · 設定**。

| タブ | できること |
| --- | --- |
| 📒 **家計簿** | 収入・支出、既定のカテゴリ、メモ、日付選択、**すべての記録がアカウントに紐づきます（現金 / WeChat / Alipay / 銀行カード / その他、アカウント名は自分で入力も可能）。上部にアカウントの絞り込みチップがあり、現金以外の記録にはアカウントを表示**、日付ごとにまとめた月間の明細、月の切り替え、カテゴリ別の割合、日別支出の棒グラフ、**月間予算の進捗バー（80% 到達時と超過時にそれぞれ通知）**、**カテゴリごとの月間予算（カテゴリの超過も通知）**、**検索**、**記録をタップしてそのまま編集**、**毎晩の記帳リマインダー**、**CSV 書き出し（Excel で文字化けしません）**、**多通貨：人民元のほかに米ドル / 日本円 / ユーロ / 香港ドル / 英ポンドも記録でき、通貨を選んでレートを入力すると換算後の人民元額が保存されます。レートは通貨ごとに記憶され、外貨の記録には元の金額と換算額の両方を表示（例 `$12.34 ≈ ¥87.61`）**、**タグ：1 件の記録に複数のタグを付けられます（旅行 / 経費精算 / リフォーム など）。家計簿ページにはタグの絞り込み行があります**、**経費精算：まず「精算待ち」にし、精算できたら「精算済み」に**、**カスタムカテゴリ（設定 → 家計簿 → カテゴリ管理）：支出と収入をそれぞれ追加・削除でき、ワンタップで既定のカテゴリに戻せます**、**CSV の取り込み（アプリ自身が書き出したファイルにも対応）** |
| ✅ **ToDo** | すばやい追加、完了チェック、重要マーク、期限と期限切れの表示、**サブタスク：ToDo に小さい手順のチェックリストを持たせられます。編集シートでチェック・追加・削除ができ、一覧の行には進捗（例 `2/5`）と細い進捗バーが出ます。ToDo を削除するとサブタスクも一緒に消えるので、孤立したデータは残りません**、**優先度は 4 段階（低 / ふつう / 高 / 緊急）：編集シートでも一覧の行からでも設定でき、行にはマークが付きます（ふつうはマークなし）。以前の ToDo は「ふつう」になります**、**ドラッグで並べ替え：ToDo を長押ししてドラッグすると順番を入れ替えられ、新しい順番は保存されます。クリックはこれまでどおり編集を開きます（検索中・「完了」フィルター・かんばん表示では並べ替えできません。黙って何も起きないのではなく、画面がその旨を伝えます）**、**リスト / かんばん表示の切り替え：かんばんは同じ ToDo を「今日が期限 / 今週中 / それ以降 / 期限なし / 完了」に分けて件数付きで表示し、空のグループは表示しません**、**繰り返しタスク（毎日 / 毎週 / 毎月、完了すると次回分を自動作成）**、**期限日のお知らせ通知（通知をタップするとアプリが開きます。通知には「1 時間後」「明日の朝」のスヌーズボタン付き）**、**編集シートの「明日に延ばす」ボタン（期限をワンタップで明日に）**、状態フィルター、**検索**、完了済みをまとめて削除 |
| ⏱️ **集中** | ポモドーロタイマー：集中 / 短い休憩 / 長い休憩、グラデーション付きリング進捗、フェーズ終了時に通知 + 振動、次のフェーズへ自動移行も可能、N 個ごとに長い休憩、**1 日の集中目標（1 / 2 / 3 / 4 / 6 / 8 または目標なし。夜になっても未達成なら一度だけ通知）**、**今日のセッション一覧**、**カウントアップ（ストップウォッチ）モード：好きなだけ集中して「完了」を押すと、その時間が集中セッションとして記録されます**、**途中で停止・スキップした集中は「中断」として残ります** |
| 📊 **統計** | 今日のポモドーロ数、連続日数、直近 7 日のグラフ、**直近 12 週間の集中ヒートマップ（1 列 = 1 週間、月曜から日曜、色が濃いほどその日の集中時間が長い）と今週の回数 / 今週の時間 / 今月の時間 / 今月の回数**、家計簿の集計、**直近 12 か月の収支トレンド**、**年間サマリー**（年間支出 / 年間収入 / 年間収支、件数、いちばん使ったカテゴリ）、**アカウント別の支出内訳**、**カテゴリ予算の進捗バー（超過分は赤）**、**今日の集中目標の進捗バー**、**ToDo ごとの投入時間（その ToDo から開始した集中のみを集計、上位 10 件）**、**累計の収支と純残高**、**精算待ちの合計額と件数、累計の精算済み金額をまとめたカード**、**前期間との比較カード（今月と先月の支出・収入、今年と去年の支出を符号付きのパーセントで比較。先月に記録がまったく無いときなど、比べる基準が無い場合は 0% や +100% をでっち上げず、比較できないと伝えます）**、**インサイト（最大 4 つのやさしい言葉の気づき：先月より多く／少なく使った額と、それを引っ張ったカテゴリ、今月いちばん使ったカテゴリ、最後の記録から何日経ったか、予算の残り。今月にデータがまったく無いときは何も表示しません）**、**月報の書き出し（今月を、共有できる PNG 画像・単体で開ける HTML ファイル（インライン CSS のみでスクリプトも外部リソースも無く、オフラインでもそのまま読めます）・PDF（A4、必要に応じて複数ページ）として書き出せます。3 つともシステムのファイル選択画面を経由するので、ストレージ権限は引き続き不要です。レポートにはその月の数字、棒グラフ、カテゴリの内訳、集中の統計、インサイトの文が入り、その月にデータが無いときは空のファイルを書かず、書き出せるものが無いと伝えます）**、**中断した集中には印が付きます** |
| ⚙️ **設定** | **表示言語（简体中文 / 繁體中文 / English / 日本語 の 4 つのチップ、切り替えるとすぐ反映され再起動は不要）**、各フェーズの長さ、振動、画面常時点灯、テーマ、**6 種類の配色（青（既定）/ インディゴ / バイオレット / ローズ / アンバー / フォレスト）。どれもライト／ダークの両方で使え、しかも全配色についてコントラストを検証しているので、ダークで読めなくなる配色はありません。システム連動の動的カラーがオンなら、選んだ配色よりそちらが優先されます**、**1 日の集中目標**、**カテゴリ予算の管理**、**予算アラートのオン・オフ**、**毎晩の記帳リマインダーと通知時刻**、**定期的な記録 / 固定費（家賃やサブスクなど毎回同じ固定費は一度設定しておくだけ：金額・種類・カテゴリ・アカウント・メモ・毎週か毎月のルール・最初の期日。期日が来た記録は自動で書き込まれます——アプリを開いたとき、または夜のリマインダーのときに補い、そのたびに次の期日を先へ進めるので、記録漏れも二重記録もありません。長く開かなかった場合も直近の 1 回分だけを補い、家計簿をあふれさせません。各ルールは一時停止 / 再開 / 削除ができ、設定の行にルールの件数と次回の期日が出ます）**、**定期のまとめ（オフ / 毎週 / 毎月。日曜 20:00 または 1 日 10:00 に送信）**、**バックアップと復元**、**自動バックアップ（システムのファイル選択画面でフォルダーを 1 つ選ぶと、アプリを開いたとき、または夜のリマインダーのときに全データを 1 つの JSON ファイルとして書き出します。1 日につき最大 1 ファイル（同じ日は上書きするので `…… (1).json` のような複製はできません）で、最新 7 件だけを残して古いものは自動で片付けます。片付けるときに削除するのは自分が作ったファイル（`DailyBook-backup-` で始まるもの）だけで、同じフォルダーに置いた他のファイルには一切触れません。失敗したときは原因（権限がない / 作成できない / 書き込めない）を正直に伝え、失敗が「前回の成功」の記録を上書きすることも、成功として表示されることもありません）**、**「セキュリティ」カードとアプリロック（既定はオフで、使うかどうかは自分で決められます。オンにするとアプリを開くときに 4〜6 桁のパスコードを求められ、バックグラウンドから戻ると再びロックされます。パスコードは「ランダムなソルト + SHA-256 のダイジェスト」としてのみ保存され、平文では絶対に保存しません。全角数字は半角に正規化されるので、全角の １２３４ で設定したパスコードでも 1234 で解除でき、自分の IME のせいで締め出されることはありません。パスコードはこの端末にしかないため、忘れたパスコードは復元できず、唯一の手段はアプリのデータを消すことです（設定画面にもそう書いてあります）。指紋や顔認証、端末のロックを使う経路はなく、アプリ自身のパスコードだけです）**、**CSV 書き出し**、**カテゴリ管理（支出と収入のカテゴリを追加 / 削除、既定に戻すのもワンタップ）**、**CSV 取り込み**、データの削除 |

さらに：色と絵文字付きのカテゴリバッジ、**ランチャーのショートカット（アプリアイコンを長押しすると、記録の追加 / ToDo の追加 / 集中の開始へ直接移動）**、タブレット / 横向きのサイドナビゲーション。

**ホーム画面ウィジェット**：今日の支出と収入、残っている ToDo の件数、今日の集中時間を表示し、タップするとアプリが開きます。フレームワーク標準の `RemoteViews`（Glance ではありません）で作られており、アプリのデータが変わったときに更新し、それ以外はシステムが許す最小間隔である 30 分ごとに更新します。文字は**システム**の言語に従い、システムがアプリ内で選んだ言語を認識できる場合はアプリ内の言語を使います。

**アプリロックは、使うかどうかを自分で決められます**：既定はオフなので、オンにしない限り何も変わりません。オンにするとアプリを開くときに 4〜6 桁のパスコードを求められ、バックグラウンドから戻ると再びロックされます。パスコードは「ランダムなソルト + SHA-256 のダイジェスト」としてのみ保存され、**平文では絶対に保存しません**。全角数字は半角に正規化されるので、全角の １２３４ で設定したパスコードでも 1234 で解除でき、自分の IME のせいで締め出されることはありません。指紋や顔認証、端末のロックを使う経路はなく、アプリ自身のパスコードだけです。そして**解除されるまで、ロック画面はあなたのデータを一切描画しません**。

**4 つの言語**：すべての画面・通知・書き出す CSV が **简体中文 / 繁體中文 / English / 日本語** に対応しています。
「設定 → 言語」で切り替えると**すぐに反映され、再起動は不要**です。ランチャーのアプリ名と
長押しショートカットの名前は**システム**の言語に従います（システム側の UI のため）。

**バックアップと復元**：すべてのデータ（アカウント・タグ・通貨・精算状態を含む家計簿、サブタスクのチェックリスト・優先度・手動の並び順を含む ToDo、
定期的な記録のルール、集中セッション、月間予算とカテゴリ予算）を 1 つの JSON ファイルに書き出し、あとからまとめて復元できます。ファイルはシステムの
ファイル選択画面で指定した場所に保存されるため、**ストレージ権限は引き続き不要**です。
復元は現在のデータを置き換えるので、実行前に確認ダイアログが表示されます。
古いバージョンが書き出したバックアップもそのまま復元でき、含まれていない項目は既定値で補われます
（タグは空、精算待ちではない、人民元のレートは 10000、優先度は「ふつう」、サブタスクなし）。

**自動バックアップ**：**システムのファイル選択画面**でフォルダーを 1 つ選びます（**ストレージ権限は引き続き不要**）。アプリを開いたとき、または夜のリマインダーのときに、全データを 1 つの JSON ファイルとして書き出します。**1 日につき最大 1 ファイル**（同じ日は上書きするので、`…… (1).json` のような複製はできません）で、**最新 7 件だけを残し**、古いものは自動で片付けます。片付けるときに削除するのは**自分が作ったファイル**（`DailyBook-backup-` で始まるもの）だけで、同じフォルダーに置いた他のものには一切触れません。失敗したときは原因（権限がない / 作成できない / 書き込めない）を正直に伝え、成功を装うことはありません：**失敗が「前回の成功」の記録を上書きすることも、成功として表示されることもありません**。

**人民元ひとつの基準**：外貨で記録しても、保存されるのは換算後の人民元額です（元の金額も保持され、一覧に表示されます）。
そのため**統計・予算・レポートはすべて人民元という 1 つの基準に揃います**。取り込みも同じ方針で、
**CSV を取り込むとき、既存の記録と完全に同じ行（日付・金額・種類・カテゴリ・アカウント・メモがすべて一致）はスキップされます**。
同じファイルを 2 回取り込んでも重複しません。読み取れない行は無視され、取り込み全体が失敗することはありません。

**固定費は自動で記録**：定期的な記録は、**アプリを開いたとき**（または夜のリマインダーの時刻）に補われ、補うたびにそのルールの次の期日が先へ進みます。だから**記録漏れも二重記録もありません**。長く開かなかった場合も直近の 1 回分だけを補い、間の期日をまとめて書き込むことはありません。

**月報の書き出し**：統計ページから、今月を**共有できる PNG 画像**、**単体で開ける HTML ファイル**（インライン CSS のみ。スクリプトも外部リソースも無いので、オフラインでもそのまま読めます）、**PDF**（A4、必要に応じて複数ページ）として書き出せます。3 つともシステムのファイル選択画面を経由するので、**ストレージ権限は引き続き不要**です。レポートにはその月の数字、棒グラフ、カテゴリの内訳、集中の統計、インサイトの文が入り、その月にデータが無いときは空のファイルを書かず、書き出せるものが無いと伝えます。

**FocusFlow（集中タイマー）**は以前の単体ポモドーロアプリです。
タイマーだけが欲しい方のために残しています。

## インストール要件

| 項目 | 要件 |
| --- | --- |
| **対応 OS** | **Android 8.0（API 26）以上**。ビルドターゲットは Android 15（API 35） |
| **APK サイズ** | 約 1.8 MB |
| **インストール方法** | 自己署名のため（ストア配信ではありません）、端末の設定で「提供元不明のアプリ」を許可する必要があります |
| **要求する権限** | 通知・振動・再起動後のリマインダー再設定（ToDo・毎晩の記帳リマインダー・定期のまとめ）の 3 つのみ。**ストレージ権限は不要**：バックアップ・CSV・月報はシステムのファイル選択画面を経由します。**v1.8 で権限は 1 つも増えていません**：アプリロックは標準 API とアプリ自身のパスコード、ウィジェットはフレームワーク標準の `RemoteViews`、自動バックアップはシステムのファイル選択画面を使います |
| **ネットワーク** | **インターネット権限は一切ありません。** どこにも送信しません |
| **データの保存先** | 端末内のみ。アンインストールすると削除されます。**上書き更新ではデータは失われません**（データベースは自動移行、現在はバージョン 6）。旧バージョンが書き込んだ行には安全な既定値が入ります（タグは空、精算待ちではない、人民元のレートは 10000、優先度は「ふつう」、サブタスクなし）。アプリロックのパスコードは「ランダムなソルト + SHA-256 のダイジェスト」としてのみ保存され、平文では保存されず、しかもこの端末にしかありません。だからこそ**忘れたパスコードは復元できず**、唯一の手段はアプリのデータを消すことです |
| **アップデート** | 全バージョンでパッケージ名と署名が同一のため、新しい APK をそのまま上書きインストールできます。更新時はデータベースが自動で移行し、既存の家計簿・ToDo・集中セッションの記録はそのまま残ります。旧バージョンが書き出したバックアップも復元でき、含まれていない項目は既定値で補われます |
| **既知の制限** | 署名されているのは正式版のみで、デバッグ版は署名が異なるため正式版に上書きインストールできません。計測中にシステムがバックグラウンドでアプリを終了すると、タイマーは中断します。ToDo のリマインダーと毎晩の記帳リマインダーはどちらも非正確アラーム（正確なアラーム権限は要求しません）のため、9:00 や 21:00 の通知が数分遅れることがあります。統計は常に人民元の基準で、外貨は入力したレートで換算されます。カテゴリを削除しても既存の記録は変わらず、カテゴリ名はその記録に残ります。1 分未満の集中は中断セッションとして記録されず、休憩はそもそも記録されません。アプリ内で言語を変えてもランチャーのアプリ名と長押しショートカットの名前は変わらず、これらはシステムの言語に従います。ドラッグでの並べ替えは通常のリスト表示でのみ使えます（検索中・「完了」フィルター・かんばん表示では並べ替えできないことを画面が伝えます）。定期的な記録はバックグラウンドで定時に書き込まれるのではなく、アプリを開いたときや夜のリマインダーのときに補うため、期日どおりの記録は次にアプリを開いたときに家計簿へ入ります。長く開かなかった場合は直近の 1 回分だけを補います。アプリロックには指紋や顔認証、端末のロックを使う経路がなく、復元もできません（忘れた場合はアプリのデータを消すしかありません）。ウィジェットが表示するのは今日の数字だけです。自動バックアップはアプリを開いたとき、または毎日のアラームが鳴ったときにだけ行われるので、アプリをまったく開かない人には新しいバックアップが残りません。また書き出される JSON は平文で、自分で選んだフォルダー（クラウド同期のフォルダーである場合もあります）に置かれます |
