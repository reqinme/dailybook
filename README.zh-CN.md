# 日常本 DailyBook · 专注时钟 FocusFlow

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

用 Kotlin + Jetpack Compose 编写的**纯离线**安卓应用。
**没有网络权限 —— 你的数据永远不会离开手机。**

---

## 软件介绍

**日常本**把五样日常工具合进一个应用：记账、生活、学习、待办、番茄钟。
底部五个标签：**记账 · 生活 · 学习 · 专注 · 统计**；设置搬到了顶栏的齿轮图标里，二级页面则在顶栏左侧显示返回箭头。

| 标签 | 功能 |
| --- | --- |
| 📒 **记账** | 支出 / 收入、预置分类、备注、日期选择、**每笔记录都归到某个账户（现金 / 微信 / 支付宝 / 银行卡 / 其他，也可以自己输入账户名），顶部有账户筛选胶囊、非现金记录会显示账户**、按月分组流水、月份切换、分类占比、每日支出柱状图、**月度预算进度条（到 80% 和超支时各提醒一次）**、**每个分类单独设月度预算（分类超支也会提醒）**、**搜索**、**点任意记录即可编辑**、**每晚提醒记账**、**导出 CSV（Excel 打开不乱码）**、**多币种：除人民币外还能记美元 / 日元 / 欧元 / 港币 / 英镑，选好币种再填一个汇率，应用存下折算后的人民币金额，汇率按币种记住，外币记录会同时显示原币金额与折算金额（如 `$12.34 ≈ ¥87.61`）**、**标签：一笔记录可以带多个标签（旅行 / 报销 / 装修……），记账页有标签筛选行**、**待报销：先把一笔标成待报销，报销到账后再标成已报销**、**自定义分类（设置 → 记账 → 分类管理）：支出和收入分别增删分类，一键就能恢复预置分类**、**导入 CSV（也认应用自己导出的文件）**、**整页只有一个滚动面：年 / 月条、汇总卡、预算与报销卡、筛选行、日历和流水都在同一个可滚页面里，列表上方不再有固定不动的卡片（之前最上面那几张卡是钉住的，只有下面的列表滚），「筛选到某一天」的那张卡也不会再重复渲染两遍** |
| ✅ **待办** | 快速添加、完成勾选、星标重要、截止日与逾期高亮、**子任务：一条待办可以带一份小步骤清单，在编辑弹窗里勾选、删除、添加，列表行会显示进度（如 `2/5`）和一条细进度条；删掉待办时它的子任务一并删除，不留孤儿数据**、**优先级四级（低 / 普通 / 高 / 紧急）：弹窗里能设，列表行上也能直接改，行上带标记（普通不标记），老待办默认「普通」**、**拖拽排序：长按待办拖动即可重排，新顺序会被保存，单击仍然是打开编辑；搜索中、已完成筛选和看板视图下不支持排序（界面会直接说明，而不是默默没反应）；列表现在真的按你拖出来的顺序排——重要的在前，然后按存下来的手动顺序，之前那个顺序只写不读**、**列表 / 看板视图切换：看板把同一批待办按「今天到期 / 本周内 / 以后 / 没有日期 / 已完成」分组并显示各组条数，空的分组不显示**、**重复任务（每天 / 每周 / 每月，勾完自动生成下一次）**、**到点提醒通知（点击通知直接打开应用，通知上还有「1 小时后」和「明天早上」两个稍后提醒按钮）**、**编辑弹窗里的「顺延到明天」按钮（一键把截止日推到明天）**、状态筛选、**搜索**、一键清除已完成 |
| ⏱️ **专注** | 番茄钟：专注 / 短休息 / 长休息，圆环渐变进度，阶段结束通知 + 震动，可选自动进入下一阶段，每 N 个番茄安排长休息，**每日专注目标（1 / 2 / 3 / 4 / 6 / 8 或不定目标，晚上还没达标会再提醒一次）**，**今日专注明细**、**正计时：想专注多久就多久，点「完成」把这段时间记成一次专注**、**中断记录：番茄模式下中途停止或跳过专注阶段，只要已过 1 分钟也会记下来并标成「中断」** |
| 📊 **统计** | 今日番茄数、连续专注天数、近 7 天柱状图（「近 7 天」这个数字和这张柱状图取的是同一个区间，不会再互相矛盾）、**近 12 周专注热力图（一列一周，周一到周日，颜色越深当天专注越久）与本周次数 / 本周时长 / 本月时长 / 本月次数（跟着你在统计页选中的月份走，不再固定按当前日历月）**、记账汇总、**近 12 个月收支趋势图**、**年度汇总**（年支出 / 年收入 / 年结余、笔数、花得最多的分类）、**账户支出分布**、**分类预算进度条（超支标红）**（分类预算只会被你手动删掉——弹窗不会再悄悄删掉它没显示的那些分类的预算）、**今日专注目标进度条**、**按待办统计投入时间（只统计从该待办发起的专注，取前 10 条）**、**累计收支与净结余**、**待报销卡片（待报销合计金额与笔数，以及累计已报销金额）**、**环比对比（本月 vs 上月看支出与收入、今年 vs 去年看支出，给出带正负号的百分比；没有可比基数时——比如上个月一条记录都没有——会直接说明两笔金额无法比较，而不是编一个 0% 或 +100%）**、**智能洞察（最多四条大白话观察：比上个月多花 / 少花了多少、以及是哪个分类拉动的，本月花得最多的分类，距上一次记账过了多少天，预算还剩多少；本月完全没有数据时一条都不显示）**、**月报导出（把本月导成一张可分享的 PNG 图片、一个独立 HTML 文件（只用内联 CSS，不含脚本、不引用任何外部资源，离线也能正常阅读）和一份 PDF（A4，页数按内容自动增加）；三种都走系统文件选择器，所以应用依然不需要存储权限；月报里有当月的数字、柱状图、分类构成、专注统计和洞察文案；本月还没有数据时会提示没有可导出的内容，而不是写一个空文件）**、**年 / 月快速切换条（◀ ▶ 加一个可点的中间区域，点开是「年 + 12 个月」选择器，带「回到本月」，跳月份一下到位，不用点很多下；记账页也有同一条）**、**原来的原始明细列表改成了标题行：「本月记录 / 分类明细 / 每日明细 / 专注记录 / 待办完成情况」各自打开独立详情页（其中「专注记录」跟着所选月份走），所有汇总卡、图表、环比、洞察和月报导出都留在统计页上**、**中断的专注会标出来** |
| 🧺 **生活** | 一条分段控件切换五个视图：**待办 / 习惯打卡 / 备忘录 / 大事记 / 重要日期**。**习惯打卡：每个习惯一行，带 emoji、名称、今天的进度（目标 + 单位，如次 / 个 / 页 / 分钟）、当前连续天数（连续 N 天）、本周打卡几天、7 天小格，用 +/− 记数、点整行也能打卡；新增 / 编辑弹窗里有 emoji、目标、单位和每周目标（每周目标现在会显示进度，如「本周 2 / 3 天」，达标后还会标出来）——背单词 / 背书计划用的就是同一套机制，也就是一个带单位与每日目标的习惯，不另做功能；背单词 / 背书计划的单位不是「次」，它就在「生活 ▸ 习惯打卡」里管理，学习页上那张叫「背单词」的卡片已经去掉了（它会打开习惯打卡页，顶栏却写着「背单词」，名不对实）**。**备忘录：两列卡片，标题加一句预览，可置顶 / 取消置顶、编辑、删除**。**大事记：按年份分组的竖向时间轴，带一条竖线（圆点 + 连接线）、标题、日期和备注；配了图会显示提示，但不渲染图片**。**重要日期：最上面一张大事卡片倒计时最近的一个（N 天 / 就是今天），其余按行列出；「只过一次」的日期过了那一天也不会消失，而是移到一个「已经过去」分组里显示已过去 N 天；每条可以是阳历或农历（支持闰月），有重复规则（只过一次 / 每年 / 每月 / 每周）和可选提醒（提前 0 / 1 / 3 / 7 天）——这个提醒现在真的会提醒你：到提醒日当天上午 9:00 发一条应用内通知（用自己的通知渠道，非精确闹钟，不新增任何权限），以前它只影响导出的 .ics；每条还能导出 .ics——写出真正的 RFC 5545 VEVENT（带 RRULE 与可选 VALARM），走系统文件选择器，导进手机日历即可** |
| 🎓 **学习** | 一个入口页：汇总卡（今天 / 本周几节课、GPA、下一场考试倒计时、未完成与逾期的作业）、今天的课程直接列在下面，再加一格格进入八个子页面的卡片。**课表：今天 / 整周两种视图，一张 7 天 × 12 节的周表（画成真正的表格：节次与星期之间有网格线，表头下面有一条分隔线，最左边的节次列和网格对齐；星期表头和网格共用同一个横向滚动状态，所以左右滑动时「周六」不会再停在错误的列上），课程块按节次区间占高度、颜色来自固定调色板；一门课带星期、起止节、周次表达式（支持 `1-16`、`1,3,5-9` 和 `1-16单` 这类单双周）、学期起始日和颜色**。**考试与复习：卡片按日期排序，带一个大倒计时（N 天 / 今天 / 已结束），展开就是这场考试的复习任务清单（勾选、删除、就地添加），还有一个「自动排复习计划」按钮，按均匀间隔给出一份建议——界面上写明这只是建议，可以自己删**。**作业与 DDL：这就是待办列表里带了课程名的那部分，按逾期 / 今天 / 本周 / 以后 / 没有日期 / 已完成分组，逾期行高亮；新增一条要填标题、课程和截止日（课程名、优先级与手动顺序现在都能完整地导出再恢复回来——以前待办从备份里恢复会丢掉课程名，作业 / DDL 的课程归属就没了）**。**成绩与 GPA：成绩按学期分组，显示分数、学分、换算后的绩点和类别；新增 / 编辑弹窗支持百分制 / 五级制 / 直接给绩点，百分制按一份写明的 4.0 分段换算，选了 5.0 口径就等比放大——而且这个口径现在是真读设置，不再从数据里猜，所以选了 5.0 不会又翻回 4.0、存下一个和你预览时不一样的数字**。**学分进度：按类别显示已修 / 要求的进度条、一个总进度，还有一个「其他已修学分」卡片用来记没有设目标的类别；类别胶囊（必修 / 选修 / 通识 / 其他）现在跟随界面语言，以前给英文 / 日文用户看的还是生硬的中文**。**奖助与证书：奖学金 / 竞赛 / 证书 / 其他按类别分组，每条带级别（国家级 / 省级 / 校级 / 院级）、日期和备注；配了图同样只给提示、不渲染图片**。**学习周报：一份只读的最近 7 天小结（专注分钟与次数、待办完成、背单词打卡、支出、逾期作业），点「导出图片」把它画成 PNG 走系统文件选择器保存；待办那一项是「目前已完成的总条数」，因为库里没有存完成日期** |
| ⚙️ **设置** | **改成了系统设置那样的列表：7 个分类——外观 / 语言 / 记账 / 专注 / 学习 / 数据与备份 / 关于与更新，每个点进去是独立子页面，原来所有设置项都没变、只是搬进对应分类**。**学习分类：学期起始日（日期选择器，用来把课表的周次换成真实日期；现在改了它就会立刻重排上课提醒，不会像以前那样一直用旧的周次编号直到重启）、GPA 计算口径（4.0 / 5.0；成绩页现在真的读这个口径，不再从数据里猜，所以选了 5.0 不会又翻回 4.0 并存下一个和你预览时不一样的数字）、上课提醒（开关 + 提前 5 / 10 / 15 / 30 分钟；只对填了上课时间的课生效）**。**关于页：应用名、包名、版本号与最低 Android 版本都是运行时从已安装的包里读出来的（刻意不写死），并说明数据都存在本机、附许可说明；检查更新页显示当前版本并打开浏览器访问 GitHub releases 页（`ACTION_VIEW`）——应用没有联网权限，所以做不了应用内检查更新，页面上就是这么如实写的**。**界面语言（简体中文 / 繁體中文 / English / 日本語，四个胶囊，切换立即生效不用重启）**、各阶段时长、震动、屏幕常亮、主题、**十二套配色（青（默认）/ 靛蓝 / 紫罗兰 / 玫红 / 琥珀 / 森林 / 天蓝 / 薄荷 / 珊瑚 / 咖啡 / 石墨 / 樱花），每套都能用在浅色和深色模式下，而且每一套的对比度都是算出来的——正文 ≥ 4.5:1、控件 ≥ 3:1，并验过十二个主色互不相同——不会出现某个配色在深色下看不清的情况；跟随系统取色打开时依然优先于所选配色**、**自定义背景图（用系统文件选择器挑任意一张图，解码走两趟采样，再大的照片也不会把内存吃光；换好之后各层表面变半透明，用蒙版滑块（0~80）决定图片透出多少，还有一个「清除」按钮把它去掉；解码失败按「没有背景」处理，不会崩）**、**每日专注目标**、**分类预算管理**、**预算提醒开关**、**每晚记账提醒与提醒时间**、**周期记账 / 固定支出（房租、订阅这类固定支出设一次就好：填金额、类型、分类、账户、备注、每周或每月的规则和首次到期日（金额必须大于 0，否则不让保存）；到期时会自动补记——打开应用时补，或者到了晚上提醒的时间补，每补一次就把下次日期往后推，所以既不会漏也不会重复记，很久没打开也只会补最近的一期，不会一次灌满整本账；每条规则可以暂停 / 恢复 / 删除，设置里那一行会显示现有几条规则、下一条什么时候到期）**、**定期小结（关闭 / 每周 / 每月，每周日 20:00 或每月 1 日 10:00 发一条；重启后由开机接收器重新排上，不会再一重启就停掉）**、**备份与恢复**、**自动备份（用系统文件选择器挑一个文件夹，应用在打开时或晚上提醒时把全部数据写成一个 JSON 文件；一天最多一份，同一天覆盖而不会多出一个副本，只保留最新的 7 份、更旧的自动清理；清理时只删自己生成的文件（`DailyBook-backup-` 前缀），你放在同一个文件夹里的其他文件一律不碰；失败会按原因如实说明（没有权限 / 建不了文件 / 写不进去），失败绝不会覆盖「上次成功备份」的记录，也绝不会显示成成功）**、**导出 CSV**、**分类管理（增删支出与收入分类，或一键恢复预置分类）**、**导入 CSV**、数据清除（关于页自己也不再带一个「检查更新」入口：它与「设置 ▸ 关于与更新」里的那条重复，整行去掉了） |

另外还有：带颜色与 emoji 的分类徽章、**桌面快捷方式（长按应用图标可直接记一笔 / 加待办 / 开始专注）**、平板 / 横屏的侧边导航布局。

**桌面小组件**：第一个显示今天的支出与收入、还剩几件待办、今天专注了多少分钟，点一下就打开应用。第二个是**考试倒计时**：显示一场考试的名称、日期与倒计时（N 天 / 今天 / 已结束），外加课程名与地点，还有一个小小「切换」热区在接下来的几场考试之间轮换，记住的是这个实例自己的选择；没有待考的考试时给一句友好提示。两个都用系统框架自带的 `RemoteViews`（不是 Glance），在应用数据变化时刷新，其余时候按系统允许的最小间隔 30 分钟刷新一次；文字跟随**系统**语言，系统认识应用内选的语言时会用应用内的语言。

**生活都在一个标签里**：生活页用一条分段控件在待办、习惯打卡、备忘录、大事记、重要日期之间切换。习惯就是一行：emoji、名称、带单位的每日目标、当前连续天数、本周完成几天和 7 天小格，用 +/− 或点整行记一次，每周目标会显示进度（如「本周 2 / 3 天」）并在达标后标出来；**背单词 / 背书计划不用另做功能，它就是一个带单位和每日目标的习惯，在「习惯打卡」里管理**。备忘录是两列卡片。大事记是按年份分组的时间轴。重要日期最上面是最近那个的倒计时卡片，并同时支持阳历与**农历**（含闰月）、重复规则、提醒（现在真的会发一条应用内通知，不只是写进导出的 .ics）、以及每条**导出 .ics**，导进手机日历即可；「只过一次」的日期过了之后会移到「已经过去」分组，显示已过去 N 天，而不是消失。

**学习也都在一个标签里**：学习页是入口页——汇总卡、今天的课程，再进八个子页面（课表、考试与复习、作业与 DDL、成绩与 GPA、学分进度、奖助与证书、学习周报，以及背单词计划）。课表是 7 × 12 的周表，画成真正的表格：网格之间有分隔线、表头下有分隔线，星期表头和网格共用同一个横向滚动状态，所以左右滑动时星期标签始终对着正确的列；课程块按节次区间占位、按课程取色，由 `1-16` 或 `1-16单` 这样的周次表达式驱动。作业就是待办列表里带课程名的那部分，按逾期 / 今天 / 本周 / 以后 / 没有日期 / 已完成分组、逾期行高亮——是同一批行，不是第二份列表。考试展开就是复习任务清单，还有一个按钮给出一份可以自己删掉的均匀复习计划。成绩把百分制 / 五级制换成绩点，周报把最近 7 天汇总成一张可以导出成 PNG 的图。

**关于与更新**：关于页的名称、包名、版本号和最低 Android 版本都是运行时从已安装的包里读的，不写死，并写明数据都在本机。**检查更新**只显示当前版本，然后交给浏览器打开 GitHub releases 页——应用没有联网权限，应用内检查更新根本做不到，页面上就是这么写的，不装作能查。关于页自己也不再带一个检查更新入口：它和「设置 ▸ 关于与更新」里那一条重复，所以整行删掉了。

**十二套配色**：青 / 靛蓝 / 紫罗兰 / 玫红 / 琥珀 / 森林 / 天蓝 / 薄荷 / 珊瑚 / 咖啡 / 石墨 / 樱花，每套都有浅色与深色两版。对比度不是靠眼睛看，而是算出来的：单元测试逐个算 WCAG 对比度，要求两种模式下正文 ≥ 4.5:1、控件 ≥ 3:1，并且十二个主色互不相同——所以哪个配色接错了、切了没变化，都逃不过构建。还可以设**自定义背景图**：用系统文件选择器挑一张图，各层表面变半透明，蒙版滑块（0~80）决定图片透出多少，另有「清除」按钮去掉它。

**四种语言**：所有界面、所有通知和导出的 CSV 都支持 **简体中文 / 繁體中文 / English / 日本語**，在「设置 → 语言」里切换，**立即生效，不用重启**。桌面图标名称与长按快捷方式的名称跟随**系统**语言，因为它们属于系统界面，不由应用自己绘制。

**备份与恢复**：把全部数据（记账及其账户、标签、币种与报销状态，待办及其子任务清单、优先级、手动顺序与课程名（这三项现在都能完整地存进去、再原样恢复回来），周期记账规则，专注记录，月度预算与分类预算，以及生活记录——备忘录、大事记、重要日期、习惯与打卡记录——和学习记录——课程、考试与复习任务、成绩、学分目标、奖助与证书）导出成一个 JSON 文件，之后可以整份恢复，换手机或重装也不用愁。文件通过系统文件选择器存到你挑的位置，所以应用**依然不需要存储权限**；恢复会覆盖当前数据，操作前会先弹确认框，而且确认文案会把它真正会动的模块一个个写清楚（恢复会清空全部 16 张表），不再只说「记账 / 待办 / 专注」；「清空全部数据」和「清除所有待办」的说明也照这个口径写，备份说明里则列出了它包含的全部模块。旧版本导出的备份仍可正常恢复——v2~v4 的老备份也认，没有的那几段就是空的，没有的字段按默认值补齐（标签为空、不是待报销、人民币汇率 10000、优先级是「普通」、没有子任务）。

**自动备份**：用**系统文件选择器**挑一个文件夹，所以**依然不需要存储权限**；应用在打开时、或者到了晚上提醒的时间，把全部数据写成一个 JSON 文件。**一天最多一份**（同一天覆盖，不会多出一个 `…… (1).json` 这样的副本），并且**只保留最新的 7 份**、更旧的自动清理；清理时**只删自己生成的文件**（`DailyBook-backup-` 前缀），你放在同一个文件夹里的其他东西一律不碰。失败会按原因如实说明（没有权限 / 建不了文件 / 写不进去），而不是假装成功：**失败绝不会覆盖「上次成功备份」的记录，也绝不会显示成成功**。

**统一按人民币统计**：虽然可以记外币，但应用存下的是折算后的人民币金额（原币金额也一并保留、列表里会显示出来），所以**所有统计、预算和报表都统一在人民币这一个口径上**。导入也一样稳妥：**导入 CSV 时，和已有记录完全相同的行（日期、金额、类型、分类、账户、备注都一样）会被跳过**，同一个文件导两遍也不会重复；读不懂的行直接忽略，不会让整次导入失败。

**固定支出自动补记**：周期记账的到期记录是**打开应用时补**的（或者到了每晚提醒的时间补），每补一次就把该规则的下次到期日往后推，所以**既不会漏记也不会记两遍**；隔了很久才打开，也只会补最近的一期，不会一口气把中间落下的几期全写进账本。

**月报导出**：统计页可以把本月导出成一张**可分享的 PNG 图片**、一个**独立 HTML 文件**（只用内联 CSS，不含脚本、不引用任何外部资源，离线也能正常阅读）和一份 **PDF**（A4，页数按内容自动增加）。三种都经系统文件选择器保存，所以应用**依然不需要存储权限**；月报里包含当月的数字、柱状图、分类构成、专注统计和洞察文案，本月还没有数据时会直接提示没有可导出的内容，而不是写一个空文件。

**专注时钟**是早期独立的番茄钟应用，保留给只需要计时器的用户。

## 安装限制

| 项目 | 要求 |
| --- | --- |
| **系统版本** | **Android 8.0（API 26）及以上**。编译目标为 Android 15（API 35） |
| **安装包大小** | 约 2 MB |
| **安装方式** | 应用为自签名（未上架应用商店），需在系统设置中允许「安装未知来源应用」 |
| **申请权限** | 只有三个：通知、震动、开机后重新排提醒（重启不会丢待办提醒、每晚记账提醒和定期小结）。**不需要存储权限**：备份、CSV 文件、月报、导出 .ics 与周报 PNG 都走系统文件选择器。**v1.10 一个权限都没加**：重要日期的提前提醒用的是同一套非精确闹钟（自己的通知渠道，9:00 本地时间），课表的表格、重排的上课提醒和这条新通知都是框架自带能力，检查更新只是打开浏览器 |
| **网络** | **完全没有网络权限**，不会向任何地方上传数据。所以「检查更新」也查不了任何东西：它只显示你当前的版本，把发布页交给浏览器 |
| **数据存放** | 只保存在本机。卸载应用会删除数据；**覆盖升级不丢数据**（数据库自动迁移，当前为第 7 版：`todos` 多了 `courseName`，并新增 11 张表——备忘录、大事记、重要日期、习惯、习惯打卡、课程、考试、复习任务、成绩、学分目标、奖助与证书），旧版本写入的记录会拿到安全的默认值（标签为空、不是待报销、人民币汇率 10000、优先级是「普通」、没有子任务、没有课程名），学期起始日在 UTC+8 下也不会再显示成早一天。v1.10 没有动任何表结构：还是第 7 版，从 v1.9 升上来不会跑迁移 |
| **升级** | 所有版本包名与签名一致，可直接用新版 APK 覆盖安装旧版；升级时数据库自动迁移，原有记账、待办、专注记录完整保留。旧版本导出的备份也仍可恢复——v2~v4 的老备份也认，没有的段就当空的，没有的字段按默认值补齐 |
| **已知限制** | 只有正式版 APK 有签名；调试版签名不同，无法覆盖安装正式版。计时过程中若被系统清理后台，计时会中断。待办提醒和每晚记账提醒用的都是非精确闹钟（不申请精确闹钟权限），9:00 或 21:00 的通知可能晚几分钟。统计始终统一在人民币口径上，外币按你填的汇率折算。删除分类不会动已有记录，分类名仍留在那些记录上。专注不足 1 分钟不会被记成中断记录，休息阶段更不会被记录。应用内切换语言不会改变桌面图标名称和长按快捷方式，它们跟随系统语言。待办的拖拽排序只在普通列表里可用：搜索中、已完成筛选和看板视图下，应用会直接说明不支持排序。周期记账不是后台定时写入，而是在打开应用或每晚提醒时补记，所以到期的记录要等下次打开应用才落到账本上，长时间没打开也只补最近的一期。今日小组件只显示当天的数字，倒计时小组件一次只显示一场考试。重要日期的提前提醒也是非精确闹钟（本地时间上午 9:00），所以和待办提醒、每晚记账提醒一样可能晚几分钟；已经过去的「只过一次」日期不会消失，而是留在列表的「已经过去」分组里，显示已过去 N 天。大事记和奖助里配的图片只给提示、不渲染（没有打包图片库），周报里的待办项是「目前已完成的总条数」，因为库里没有存完成日期。作业与 DDL 就是待办列表按课程名筛出来的，背单词计划就是一个习惯，都不是单独的表格。统计页和记账页都跟着你选中的月份走，所以数字看着不对时先看看月份（换月份会同时清掉按天筛选，不会再留下一个自相矛盾的「0 笔」筛选卡）。**这一版（v1.9）去掉了应用锁**：没有密码界面、没有指纹 / 人脸这条路径，数据也不做任何加密——那个锁只存在于 v1.8，按你的要求整条移除了。自动备份只在打开应用或每日闹钟响的时候做，所以一直不打开应用就不会有新的备份；写出的 JSON 是明文，放在你自己挑的文件夹里，那个文件夹可能是云同步盘 |
