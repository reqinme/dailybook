# 日常本 DailyBook · 专注时钟 FocusFlow

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

用 Kotlin + Jetpack Compose 编写的**纯离线**安卓应用。
**没有网络权限 —— 你的数据永远不会离开手机。**

---

## 软件介绍

**日常本**把三样日常工具合进一个应用：记账、待办、番茄钟。
底部五个标签：**记账 · 待办 · 专注 · 统计 · 设置**。

| 标签 | 功能 |
| --- | --- |
| 📒 **记账** | 支出 / 收入、预置分类、备注、日期选择、按月分组流水、月份切换、分类占比、每日支出柱状图、**月度预算进度条**、**搜索**、**点任意记录即可编辑** |
| ✅ **待办** | 快速添加、完成勾选、星标重要、截止日与逾期高亮、状态筛选、**搜索**、一键清除已完成 |
| ⏱️ **专注** | 番茄钟：专注 / 短休息 / 长休息，圆环渐变进度，阶段结束通知 + 震动，可选自动进入下一阶段，每 N 个番茄安排长休息，**今日专注明细** |
| 📊 **统计** | 今日番茄数、连续专注天数、近 7 天柱状图、记账汇总 |
| ⚙️ **设置** | 各阶段时长、震动、屏幕常亮、主题、数据清除 |

另外还有：带颜色与 emoji 的分类徽章、平板 / 横屏侧边导航布局、中英文界面。

**专注时钟**是早期独立的番茄钟应用，保留给只需要计时器的用户。

## 安装限制

| 项目 | 要求 |
| --- | --- |
| **系统版本** | **Android 8.0（API 26）及以上**。编译目标为 Android 15（API 35） |
| **安装包大小** | 约 1.6 MB |
| **安装方式** | 应用为自签名（未上架应用商店），需在系统设置中允许「安装未知来源应用」 |
| **申请权限** | 只有两个：通知、震动 |
| **网络** | **完全没有网络权限**，不会向任何地方上传数据 |
| **数据存放** | 只保存在本机。卸载应用会删除数据；**覆盖升级不丢数据**（数据库自动迁移） |
| **升级** | 所有版本包名与签名一致，可直接用新版 APK 覆盖安装旧版 |
| **已知限制** | 只有正式版 APK 有签名；调试版签名不同，无法覆盖安装正式版。计时过程中若被系统清理后台，计时会中断 |
