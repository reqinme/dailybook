# 日常本 DailyBook · 专注时钟 FocusFlow

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

用 Kotlin + Jetpack Compose 编写的**纯离线**安卓应用。
**没有网络权限 —— 你的数据永远不会离开手机。**

---

## 软件介绍

**日常本**把三样日常工具合进一个应用：记账、待办、番茄钟。
底部五个标签：**记账 · 待办 · 专注 · 统计 · 设置**。

| 标签 | 功能 |
| --- | --- |
| 📒 **记账** | 支出 / 收入、预置分类、备注、日期选择、**每笔记录都归到某个账户（现金 / 微信 / 支付宝 / 银行卡 / 其他，也可以自己输入账户名），顶部有账户筛选胶囊、非现金记录会显示账户**、按月分组流水、月份切换、分类占比、每日支出柱状图、**月度预算进度条（到 80% 和超支时各提醒一次）**、**每个分类单独设月度预算（分类超支也会提醒）**、**搜索**、**点任意记录即可编辑**、**每晚提醒记账**、**导出 CSV（Excel 打开不乱码）**、**多币种：除人民币外还能记美元 / 日元 / 欧元 / 港币 / 英镑，选好币种再填一个汇率，应用存下折算后的人民币金额，汇率按币种记住，外币记录会同时显示原币金额与折算金额（如 `$12.34 ≈ ¥87.61`）**、**标签：一笔记录可以带多个标签（旅行 / 报销 / 装修……），记账页有标签筛选行**、**待报销：先把一笔标成待报销，报销到账后再标成已报销**、**自定义分类（设置 → 记账 → 分类管理）：支出和收入分别增删分类，一键就能恢复预置分类**、**导入 CSV（也认应用自己导出的文件）** |
| ✅ **待办** | 快速添加、完成勾选、星标重要、截止日与逾期高亮、**子任务：一条待办可以带一份小步骤清单，在编辑弹窗里勾选、删除、添加，列表行会显示进度（如 `2/5`）和一条细进度条；删掉待办时它的子任务一并删除，不留孤儿数据**、**优先级四级（低 / 普通 / 高 / 紧急）：弹窗里能设，列表行上也能直接改，行上带标记（普通不标记），老待办默认「普通」**、**拖拽排序：长按待办拖动即可重排，新顺序会被保存，单击仍然是打开编辑；搜索中、已完成筛选和看板视图下不支持排序（界面会直接说明，而不是默默没反应）**、**列表 / 看板视图切换：看板把同一批待办按「今天到期 / 本周内 / 以后 / 没有日期 / 已完成」分组并显示各组条数，空的分组不显示**、**重复任务（每天 / 每周 / 每月，勾完自动生成下一次）**、**到点提醒通知（点击通知直接打开应用，通知上还有「1 小时后」和「明天早上」两个稍后提醒按钮）**、**编辑弹窗里的「顺延到明天」按钮（一键把截止日推到明天）**、状态筛选、**搜索**、一键清除已完成 |
| ⏱️ **专注** | 番茄钟：专注 / 短休息 / 长休息，圆环渐变进度，阶段结束通知 + 震动，可选自动进入下一阶段，每 N 个番茄安排长休息，**每日专注目标（1 / 2 / 3 / 4 / 6 / 8 或不定目标，晚上还没达标会再提醒一次）**，**今日专注明细**、**正计时：想专注多久就多久，点「完成」把这段时间记成一次专注**、**中断记录：番茄模式下中途停止或跳过专注阶段，只要已过 1 分钟也会记下来并标成「中断」** |
| 📊 **统计** | 今日番茄数、连续专注天数、近 7 天柱状图、**近 12 周专注热力图（一列一周，周一到周日，颜色越深当天专注越久）与本周次数 / 本周时长 / 本月时长 / 本月次数**、记账汇总、**近 12 个月收支趋势图**、**年度汇总**（年支出 / 年收入 / 年结余、笔数、花得最多的分类）、**账户支出分布**、**分类预算进度条（超支标红）**、**今日专注目标进度条**、**按待办统计投入时间（只统计从该待办发起的专注，取前 10 条）**、**累计收支与净结余**、**待报销卡片（待报销合计金额与笔数，以及累计已报销金额）**、**环比对比（本月 vs 上月看支出与收入、今年 vs 去年看支出，给出带正负号的百分比；没有可比基数时——比如上个月一条记录都没有——会直接说明两笔金额无法比较，而不是编一个 0% 或 +100%）**、**智能洞察（最多四条大白话观察：比上个月多花 / 少花了多少、以及是哪个分类拉动的，本月花得最多的分类，距上一次记账过了多少天，预算还剩多少；本月完全没有数据时一条都不显示）**、**月报导出（把本月导成一张可分享的 PNG 图片、一个独立 HTML 文件（只用内联 CSS，不含脚本、不引用任何外部资源，离线也能正常阅读）和一份 PDF（A4，页数按内容自动增加）；三种都走系统文件选择器，所以应用依然不需要存储权限；月报里有当月的数字、柱状图、分类构成、专注统计和洞察文案；本月还没有数据时会提示没有可导出的内容，而不是写一个空文件）**、**中断的专注会标出来** |
| ⚙️ **设置** | **界面语言（简体中文 / 繁體中文 / English / 日本語，四个胶囊，切换立即生效不用重启）**、各阶段时长、震动、屏幕常亮、主题、**六套配色（青（默认）/ 靛蓝 / 紫罗兰 / 玫红 / 琥珀 / 森林），每套都能用在浅色和深色模式下，而且每一套都验过对比度，不会出现某个配色在深色下看不清的情况；跟随系统取色打开时依然优先于所选配色**、**每日专注目标**、**分类预算管理**、**预算提醒开关**、**每晚记账提醒与提醒时间**、**周期记账 / 固定支出（房租、订阅这类固定支出设一次就好：填金额、类型、分类、账户、备注、每周或每月的规则和首次到期日；到期时会自动补记——打开应用时补，或者到了晚上提醒的时间补，每补一次就把下次日期往后推，所以既不会漏也不会重复记，很久没打开也只会补最近的一期，不会一次灌满整本账；每条规则可以暂停 / 恢复 / 删除，设置里那一行会显示现有几条规则、下一条什么时候到期）**、**定期小结（关闭 / 每周 / 每月，每周日 20:00 或每月 1 日 10:00 发一条）**、**备份与恢复**、**自动备份（用系统文件选择器挑一个文件夹，应用在打开时或晚上提醒时把全部数据写成一个 JSON 文件；一天最多一份，同一天覆盖而不会多出一个副本，只保留最新的 7 份、更旧的自动清理；清理时只删自己生成的文件（`DailyBook-backup-` 前缀），你放在同一个文件夹里的其他文件一律不碰；失败会按原因如实说明（没有权限 / 建不了文件 / 写不进去），失败绝不会覆盖「上次成功备份」的记录，也绝不会显示成成功）**、**「安全」卡片与应用锁（默认关闭，你自己决定要不要开；开启后打开应用要输入 4~6 位数字密码，从后台回来会重新上锁；密码只以「随机盐 + SHA-256 摘要」保存，绝不存明文；全角数字会先归一化成半角，所以用全角 １２３４ 设的密码照样能用 1234 解锁，不会被自己的输入法锁在门外；因为密码只存在这台设备上，忘记密码无法找回，唯一的办法是清除应用数据——设置页里也是这么写的；没有指纹 / 人脸，也没有设备锁这条路径，用的就是应用自己的密码）**、**导出 CSV**、**分类管理（增删支出与收入分类，或一键恢复预置分类）**、**导入 CSV**、数据清除 |

另外还有：带颜色与 emoji 的分类徽章、**桌面快捷方式（长按应用图标可直接记一笔 / 加待办 / 开始专注）**、平板 / 横屏的侧边导航布局。

**桌面小组件**：显示今天的支出与收入、还剩几件待办、今天专注了多少分钟，点一下就打开应用。它用的是系统框架自带的 `RemoteViews`（不是 Glance），在应用数据变化时刷新，其余时候按系统允许的最小间隔 30 分钟刷新一次；文字跟随**系统**语言，系统认识应用内选的语言时会用应用内的语言。

**应用锁，要不要开由你决定**：默认关闭，不开就什么都不变。开启后打开应用要输入 4~6 位数字密码，从后台回来会重新上锁。密码只以「随机盐 + SHA-256 摘要」保存，**绝不存明文**；全角数字会先归一化成半角，所以用全角 １２３４ 设的密码照样能用 1234 解锁，不会被自己的输入法锁在门外。没有指纹 / 人脸，也没有设备锁这条路径——用的就是应用自己的密码，而且**验证通过前锁屏不渲染你的任何数据**。

**四种语言**：所有界面、所有通知和导出的 CSV 都支持 **简体中文 / 繁體中文 / English / 日本語**，在「设置 → 语言」里切换，**立即生效，不用重启**。桌面图标名称与长按快捷方式的名称跟随**系统**语言，因为它们属于系统界面，不由应用自己绘制。

**备份与恢复**：把全部数据（记账及其账户、标签、币种与报销状态，待办及其子任务清单、优先级与手动顺序，周期记账规则，专注记录，月度预算与分类预算）导出成一个 JSON 文件，之后可以整份恢复，换手机或重装也不用愁。文件通过系统文件选择器存到你挑的位置，所以应用**依然不需要存储权限**；恢复会覆盖当前数据，操作前会先弹确认框。旧版本导出的备份仍可正常恢复，没有的字段按默认值补齐（标签为空、不是待报销、人民币汇率 10000、优先级是「普通」、没有子任务）。

**自动备份**：用**系统文件选择器**挑一个文件夹，所以**依然不需要存储权限**；应用在打开时、或者到了晚上提醒的时间，把全部数据写成一个 JSON 文件。**一天最多一份**（同一天覆盖，不会多出一个 `…… (1).json` 这样的副本），并且**只保留最新的 7 份**、更旧的自动清理；清理时**只删自己生成的文件**（`DailyBook-backup-` 前缀），你放在同一个文件夹里的其他东西一律不碰。失败会按原因如实说明（没有权限 / 建不了文件 / 写不进去），而不是假装成功：**失败绝不会覆盖「上次成功备份」的记录，也绝不会显示成成功**。

**统一按人民币统计**：虽然可以记外币，但应用存下的是折算后的人民币金额（原币金额也一并保留、列表里会显示出来），所以**所有统计、预算和报表都统一在人民币这一个口径上**。导入也一样稳妥：**导入 CSV 时，和已有记录完全相同的行（日期、金额、类型、分类、账户、备注都一样）会被跳过**，同一个文件导两遍也不会重复；读不懂的行直接忽略，不会让整次导入失败。

**固定支出自动补记**：周期记账的到期记录是**打开应用时补**的（或者到了每晚提醒的时间补），每补一次就把该规则的下次到期日往后推，所以**既不会漏记也不会记两遍**；隔了很久才打开，也只会补最近的一期，不会一口气把中间落下的几期全写进账本。

**月报导出**：统计页可以把本月导出成一张**可分享的 PNG 图片**、一个**独立 HTML 文件**（只用内联 CSS，不含脚本、不引用任何外部资源，离线也能正常阅读）和一份 **PDF**（A4，页数按内容自动增加）。三种都经系统文件选择器保存，所以应用**依然不需要存储权限**；月报里包含当月的数字、柱状图、分类构成、专注统计和洞察文案，本月还没有数据时会直接提示没有可导出的内容，而不是写一个空文件。

**专注时钟**是早期独立的番茄钟应用，保留给只需要计时器的用户。

## 安装限制

| 项目 | 要求 |
| --- | --- |
| **系统版本** | **Android 8.0（API 26）及以上**。编译目标为 Android 15（API 35） |
| **安装包大小** | 约 1.8 MB |
| **安装方式** | 应用为自签名（未上架应用商店），需在系统设置中允许「安装未知来源应用」 |
| **申请权限** | 只有三个：通知、震动、开机后重新排提醒（重启不会丢待办提醒、每晚记账提醒和定期小结）。**不需要存储权限**：备份、CSV 文件与月报都走系统文件选择器。**v1.8 一个权限都没加**：应用锁用的是系统自带接口加应用自己的密码，小组件用的是框架自带的 `RemoteViews`，自动备份走系统文件选择器 |
| **网络** | **完全没有网络权限**，不会向任何地方上传数据 |
| **数据存放** | 只保存在本机。卸载应用会删除数据；**覆盖升级不丢数据**（数据库自动迁移，当前为第 6 版），旧版本写入的记录会拿到安全的默认值（标签为空、不是待报销、人民币汇率 10000、优先级是「普通」、没有子任务）。应用锁的密码只以「随机盐 + SHA-256 摘要」保存、不存明文，而且只存在本机——所以**忘记密码无法找回**，唯一的办法是清除应用数据 |
| **升级** | 所有版本包名与签名一致，可直接用新版 APK 覆盖安装旧版；升级时数据库自动迁移，原有记账、待办、专注记录完整保留。旧版本导出的备份也仍可恢复，没有的字段按默认值补齐 |
| **已知限制** | 只有正式版 APK 有签名；调试版签名不同，无法覆盖安装正式版。计时过程中若被系统清理后台，计时会中断。待办提醒和每晚记账提醒用的都是非精确闹钟（不申请精确闹钟权限），9:00 或 21:00 的通知可能晚几分钟。统计始终统一在人民币口径上，外币按你填的汇率折算。删除分类不会动已有记录，分类名仍留在那些记录上。专注不足 1 分钟不会被记成中断记录，休息阶段更不会被记录。应用内切换语言不会改变桌面图标名称和长按快捷方式，它们跟随系统语言。待办的拖拽排序只在普通列表里可用：搜索中、已完成筛选和看板视图下，应用会直接说明不支持排序。周期记账不是后台定时写入，而是在打开应用或每晚提醒时补记，所以到期的记录要等下次打开应用才落到账本上，长时间没打开也只补最近的一期。应用锁没有指纹 / 人脸，也没有设备锁这条路径，而且无法找回密码：忘记密码只能清除应用数据。小组件只显示当天的数字。自动备份只在打开应用或每日闹钟响的时候做，所以一直不打开应用就不会有新的备份；写出的 JSON 是明文，放在你自己挑的文件夹里，那个文件夹可能是云同步盘 |
