# 日常本 DailyBook · 專注時鐘 FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

以 Kotlin + Jetpack Compose 撰寫的**純離線** Android 應用程式。
**沒有網路權限 —— 你的資料永遠不會離開手機。**

---

## 軟體介紹

**日常本**把三樣日常工具整合進一個應用程式：記帳、待辦、番茄鐘。
底部五個頁籤：**記帳 · 待辦 · 專注 · 統計 · 設定**。

| 頁籤 | 功能 |
| --- | --- |
| 📒 **記帳** | 支出 / 收入、預設分類、備註、日期選擇、**每一筆紀錄都歸屬某個帳戶（現金 / 微信 / 支付寶 / 銀行卡 / 其他，也可以自己輸入帳戶名稱），頂端有帳戶篩選膠囊、非現金的紀錄會顯示帳戶**、依月份分組的流水、月份切換、分類佔比、每日支出長條圖、**每月預算進度條（到 80% 與超支時各提醒一次）**、**每個分類各自設定每月預算（分類超支也會提醒）**、**搜尋**、**點任一筆紀錄即可編輯**、**每晚提醒記帳**、**匯出 CSV（Excel 開啟不亂碼）**、**多幣別：除了人民幣還能記美金 / 日圓 / 歐元 / 港幣 / 英鎊，選好幣別再填一個匯率，應用程式會存下換算後的人民幣金額，匯率按幣別記住，外幣紀錄會同時顯示原幣金額與換算金額（如 `$12.34 ≈ ¥87.61`）**、**標籤：一筆紀錄可以帶多個標籤（旅行 / 報帳 / 裝修……），記帳頁有標籤篩選列**、**待報帳：先把一筆標成待報帳，報帳入帳後再標成已報帳**、**自訂分類（設定 → 記帳 → 分類管理）：支出與收入分別增刪分類，一鍵就能恢復預設分類**、**匯入 CSV（也認應用程式自己匯出的檔案）** |
| ✅ **待辦** | 快速新增、完成勾選、標記重要、截止日與逾期標示、**子任務：一則待辦可以帶一份小步驟清單，在編輯視窗裡勾選、刪除、新增，清單列會顯示進度（如 `2/5`）與一條細進度條；刪掉待辦時它的子任務一併刪除，不留孤兒資料**、**優先級四級（低 / 普通 / 高 / 緊急）：視窗裡能設定，清單列上也能直接改，列上帶標記（普通不標記），舊待辦預設為「普通」**、**拖曳排序：長按待辦拖動即可重排，新順序會被儲存，單擊仍然是開啟編輯；搜尋中、已完成篩選與看板檢視下不支援排序（介面會直接說明，而不是默默沒反應）**、**清單 / 看板檢視切換：看板把同一批待辦按「今天到期 / 本週內 / 以後 / 沒有日期 / 已完成」分組並顯示各組筆數，空的分組不顯示**、**重複任務（每天 / 每週 / 每月，完成後自動產生下一次）**、**到期提醒通知（點通知直接開啟應用程式，通知上還有「1 小時後」與「明天早上」兩個稍後提醒按鈕）**、**編輯視窗裡的「順延到明天」按鈕（一鍵把截止日推到明天）**、狀態篩選、**搜尋**、一鍵清除已完成 |
| ⏱️ **專注** | 番茄鐘：專注 / 短休息 / 長休息，圓環漸層進度，階段結束通知 + 震動，可選自動進入下一階段，每 N 個番茄安排長休息，**每日專注目標（1 / 2 / 3 / 4 / 6 / 8 或不定目標，晚上還沒達標會再提醒一次）**，**今日專注明細**、**正計時：想專注多久就多久，點「完成」把這段時間記成一次專注**、**中斷紀錄：番茄模式下中途停止或跳過專注階段，只要已過 1 分鐘也會記下來並標成「中斷」** |
| 📊 **統計** | 今日番茄數、連續專注天數、近 7 天長條圖、**近 12 週專注熱力圖（一欄一週，週一到週日，顏色越深代表當天專注越久）與本週次數 / 本週時長 / 本月時長 / 本月次數**、記帳彙總、**近 12 個月收支趨勢圖**、**年度彙總**（年支出 / 年收入 / 年結餘、筆數、花費最多的分類）、**帳戶支出分佈**、**分類預算進度條（超支標紅）**、**今日專注目標進度條**、**依待辦統計投入時間（只統計從該待辦發起的專注，取前 10 筆）**、**累計收支與淨結餘**、**待報帳卡片（待報帳合計金額與筆數，以及累計已報帳金額）**、**環比對比（本月 vs 上月看支出與收入、今年 vs 去年看支出，給出帶正負號的百分比；沒有可比基準時——例如上個月一筆紀錄都沒有——會直接說明兩筆金額無法比較，而不是編一個 0% 或 +100%）**、**智慧洞察（最多四條白話觀察：比上個月多花 / 少花了多少、以及是哪個分類拉動的，本月花得最多的分類，距上一次記帳過了多少天，預算還剩多少；本月完全沒有資料時一條都不顯示）**、**月報匯出（把本月匯出成一張可分享的 PNG 圖片、一個獨立 HTML 檔案（只用內嵌 CSS，不含腳本、不引用任何外部資源，離線也能正常閱讀）和一份 PDF（A4，頁數依內容自動增加）；三種都走系統檔案選擇器，所以應用程式依然不需要儲存權限；月報裡有當月的數字、長條圖、分類組成、專注統計與洞察文字；本月還沒有資料時會提示沒有可匯出的內容，而不是寫一個空檔案）**、**中斷的專注會標示出來** |
| ⚙️ **設定** | **介面語言（简体中文 / 繁體中文 / English / 日本語，四個膠囊，切換立即生效不用重新啟動）**、各階段時長、震動、螢幕恆亮、主題、**六套配色（青（預設）/ 靛藍 / 紫羅蘭 / 玫紅 / 琥珀 / 森林），每套都能用在淺色與深色模式下，而且每一套都驗過對比度，不會出現某個配色在深色下看不清的情況；跟隨系統取色開啟時依然優先於所選配色**、**每日專注目標**、**分類預算管理**、**預算提醒開關**、**每晚記帳提醒與提醒時間**、**週期記帳 / 固定支出（房租、訂閱這類固定支出設定一次就好：填金額、類型、分類、帳戶、備註、每週或每月的規則與首次到期日；到期時會自動補記——打開應用程式時補，或者到了晚上提醒的時間補，每補一次就把下次日期往後推，所以既不會漏也不會重複記，很久沒打開也只會補最近的一期，不會一次灌滿整本帳；每條規則可以暫停 / 恢復 / 刪除，設定裡那一列會顯示目前有幾條規則、下一條什麼時候到期）**、**定期小結（關閉 / 每週 / 每月，每週日 20:00 或每月 1 日 10:00 發一則）**、**備份與還原**、**自動備份（用系統檔案選擇器挑一個資料夾，應用程式在開啟時或晚上提醒時把全部資料寫成一個 JSON 檔案；一天最多一份，同一天覆寫而不會多出一個副本，只保留最新的 7 份、更舊的自動清理；清理時只刪自己產生的檔案（`DailyBook-backup-` 前綴），你放在同一個資料夾裡的其他檔案一律不碰；失敗會按原因如實說明（沒有權限 / 建不了檔案 / 寫不進去），失敗絕不會覆寫「上次成功備份」的紀錄，也絕不會顯示成成功）**、**「安全」卡片與應用程式鎖（預設關閉，你自己決定要不要開；開啟後打開應用程式要輸入 4~6 位數字密碼，從背景回來會重新上鎖；密碼只以「隨機鹽 + SHA-256 摘要」保存，絕不存明文；全角數字會先正規化成半角，所以用全角 １２３４ 設的密碼照樣能用 1234 解鎖，不會被自己的輸入法鎖在門外；因為密碼只存在這台裝置上，忘記密碼無法找回，唯一的辦法是清除應用程式資料——設定頁裡也是這麼寫的；沒有指紋 / 臉部辨識，也沒有裝置鎖這條路徑，用的就是應用程式自己的密碼）**、**匯出 CSV**、**分類管理（增刪支出與收入分類，或一鍵恢復預設分類）**、**匯入 CSV**、資料清除 |

另外還有：帶顏色與 emoji 的分類徽章、**桌面捷徑（長按應用程式圖示可直接記一筆 / 加待辦 / 開始專注）**、平板 / 橫向的側邊導覽版面。

**桌面小工具**：顯示今天的支出與收入、還剩幾件待辦、今天專注了多少分鐘，點一下就開啟應用程式。它用的是系統框架自帶的 `RemoteViews`（不是 Glance），在應用程式資料變動時重新整理，其餘時候按系統允許的最小間隔 30 分鐘重新整理一次；文字跟隨**系統**語言，系統認識應用程式內選的語言時會用應用程式內的語言。

**應用程式鎖，要不要開由你決定**：預設關閉，不開就什麼都不變。開啟後打開應用程式要輸入 4~6 位數字密碼，從背景回來會重新上鎖。密碼只以「隨機鹽 + SHA-256 摘要」保存，**絕不存明文**；全角數字會先正規化成半角，所以用全角 １２３４ 設的密碼照樣能用 1234 解鎖，不會被自己的輸入法鎖在門外。沒有指紋 / 臉部辨識，也沒有裝置鎖這條路徑——用的就是應用程式自己的密碼，而且**驗證通過前鎖定畫面不渲染你的任何資料**。

**四種語言**：所有介面、所有通知與匯出的 CSV 都支援 **简体中文 / 繁體中文 / English / 日本語**，在「設定 → 語言」切換，**立即生效，不用重新啟動**。桌面圖示名稱與長按捷徑的名稱跟隨**系統**語言，因為它們屬於系統介面，不是由應用程式自行繪製。

**備份與還原**：把全部資料（記帳及其帳戶、標籤、幣別與報帳狀態，待辦及其子任務清單、優先級與手動順序，週期記帳規則，專注紀錄，每月預算與分類預算）匯出成一個 JSON 檔案，之後可以整份還原，換手機或重裝都不必擔心。檔案透過系統檔案選擇器存到你自己挑的位置，因此應用程式**仍然不需要儲存權限**；還原會覆蓋目前資料，操作前會先顯示確認對話框。舊版本寫出的備份仍可正常還原，缺少的欄位會以預設值補上（標籤為空、不是待報帳、人民幣匯率 10000、優先級是「普通」、沒有子任務）。

**自動備份**：用**系統檔案選擇器**挑一個資料夾，所以**仍然不需要儲存權限**；應用程式在開啟時、或者到了晚上提醒的時間，把全部資料寫成一個 JSON 檔案。**一天最多一份**（同一天覆寫，不會多出一個 `…… (1).json` 這樣的副本），並且**只保留最新的 7 份**、更舊的自動清理；清理時**只刪自己產生的檔案**（`DailyBook-backup-` 前綴），你放在同一個資料夾裡的其他東西一律不碰。失敗會按原因如實說明（沒有權限 / 建不了檔案 / 寫不進去），而不是假裝成功：**失敗絕不會覆寫「上次成功備份」的紀錄，也絕不會顯示成成功**。

**統一以人民幣統計**：雖然可以記外幣，但應用程式存下的是換算後的人民幣金額（原幣金額也一併保留、清單裡會顯示出來），所以**所有統計、預算與報表都統一在人民幣這一個基準上**。匯入也一樣謹慎：**匯入 CSV 時，與現有紀錄完全相同的列（日期、金額、類型、分類、帳戶、備註都一樣）會被略過**，同一個檔案匯入兩次也不會重複；讀不懂的列直接忽略，不會讓整次匯入失敗。

**固定支出自動補記**：週期記帳的到期紀錄是**打開應用程式時補**的（或者到了每晚提醒的時間補），每補一次就把該規則的下次到期日往後推，所以**既不會漏記也不會記兩遍**；隔了很久才打開，也只會補最近的一期，不會一口氣把中間落下的幾期全寫進帳本。

**月報匯出**：統計頁可以把本月匯出成一張**可分享的 PNG 圖片**、一個**獨立 HTML 檔案**（只用內嵌 CSS，不含腳本、不引用任何外部資源，離線也能正常閱讀）和一份 **PDF**（A4，頁數依內容自動增加）。三種都經系統檔案選擇器儲存，所以應用程式**仍然不需要儲存權限**；月報裡包含當月的數字、長條圖、分類組成、專注統計與洞察文字，本月還沒有資料時會直接提示沒有可匯出的內容，而不是寫一個空檔案。

**專注時鐘**是早期獨立的番茄鐘應用程式，保留給只需要計時器的使用者。

## 安裝限制

| 項目 | 要求 |
| --- | --- |
| **系統版本** | **Android 8.0（API 26）以上**。編譯目標為 Android 15（API 35） |
| **安裝檔大小** | 約 1.8 MB |
| **安裝方式** | 應用程式為自行簽章（未上架商店），需在系統設定中允許「安裝未知來源的應用程式」 |
| **要求權限** | 只有三項：通知、震動、開機後重新排程提醒（重新啟動不會遺失待辦提醒、每晚記帳提醒與定期小結）。**不需要儲存權限**：備份、CSV 檔案與月報都透過系統檔案選擇器處理。**v1.8 一個權限都沒加**：應用程式鎖用的是系統自帶介面加應用程式自己的密碼，小工具用的是框架自帶的 `RemoteViews`，自動備份走系統檔案選擇器 |
| **網路** | **完全沒有網路權限**，不會把資料上傳到任何地方 |
| **資料存放** | 只存在本機。解除安裝會刪除資料；**覆蓋升級不會遺失資料**（資料庫自動遷移，目前為第 6 版），舊版本寫入的紀錄會取得安全的預設值（標籤為空、不是待報帳、人民幣匯率 10000、優先級是「普通」、沒有子任務）。應用程式鎖的密碼只以「隨機鹽 + SHA-256 摘要」保存、不存明文，而且只存在本機——所以**忘記密碼無法找回**，唯一的辦法是清除應用程式資料 |
| **升級** | 所有版本套件名稱與簽章一致，可直接用新版 APK 覆蓋安裝舊版；升級時資料庫自動遷移，原有的記帳、待辦與專注紀錄完整保留。舊版本匯出的備份也仍可還原，缺少的欄位會以預設值補上 |
| **已知限制** | 只有正式版 APK 有簽章；測試版簽章不同，無法覆蓋安裝正式版。計時過程若被系統清除背景，計時會中斷。待辦提醒與每晚記帳提醒用的都是非精確鬧鐘（不申請精確鬧鐘權限），9:00 或 21:00 的通知可能晚幾分鐘。統計一律以人民幣為基準，外幣按你填的匯率換算。刪除分類不會動到既有紀錄，分類名稱仍留在那些紀錄上。專注不足 1 分鐘不會被記成中斷紀錄，休息階段更不會被記錄。應用程式內切換語言不會改變桌面圖示名稱與長按捷徑，它們跟隨系統語言。待辦的拖曳排序只在一般清單裡可用：搜尋中、已完成篩選與看板檢視下，應用程式會直接說明不支援排序。週期記帳不是背景定時寫入，而是在打開應用程式或每晚提醒時補記，所以到期的紀錄要等下次打開應用程式才落到帳本上，很久沒打開也只補最近的一期。應用程式鎖沒有指紋 / 臉部辨識，也沒有裝置鎖這條路徑，而且無法找回密碼：忘記密碼只能清除應用程式資料。小工具只顯示當天的數字。自動備份只在打開應用程式或每日鬧鐘響的時候做，所以一直不打開應用程式就不會有新的備份；寫出的 JSON 是明文，放在你自己挑的資料夾裡，那個資料夾可能是雲端同步空間 |
