# 日常本 DailyBook · 專注時鐘 FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

以 Kotlin + Jetpack Compose 撰寫的**純離線** Android 應用程式。
**沒有網路權限 —— 你的資料永遠不會離開手機。**

---

## 軟體介紹

**日常本**把三樣日常工具整合進一個應用程式：記帳、待辦、番茄鐘。
底部五個頁籤：**記帳 · 待辦 · 專注 · 統計 · 設定**。

| 頁籤 | 功能 |
| --- | --- |
| 📒 **記帳** | 支出 / 收入、預設分類、備註、日期選擇、依月份分組的流水、月份切換、分類佔比、每日支出長條圖、**每月預算進度條**、**搜尋**、**點任一筆紀錄即可編輯**、**匯出 CSV（Excel 開啟不亂碼）** |
| ✅ **待辦** | 快速新增、完成勾選、標記重要、截止日與逾期標示、**重複任務（每天 / 每週 / 每月，完成後自動產生下一次）**、**到期提醒通知**、狀態篩選、**搜尋**、一鍵清除已完成 |
| ⏱️ **專注** | 番茄鐘：專注 / 短休息 / 長休息，圓環漸層進度，階段結束通知 + 震動，可選自動進入下一階段，每 N 個番茄安排長休息，**今日專注明細** |
| 📊 **統計** | 今日番茄數、連續專注天數、近 7 天長條圖、記帳彙總、**近 12 個月收支趨勢圖**、**年度彙總**（年支出 / 年收入 / 年結餘、筆數、花費最多的分類）、**累計收支與淨結餘** |
| ⚙️ **設定** | 各階段時長、震動、螢幕恆亮、主題、**備份與還原**、**匯出 CSV**、資料清除 |

另外還有：帶顏色與 emoji 的分類徽章、平板 / 橫向的側邊導覽版面。

**備份與還原**：把全部資料（記帳、待辦、專注紀錄、每月預算）匯出成一個 JSON 檔案，之後可以整份還原，換手機或重裝都不必擔心。檔案透過系統檔案選擇器存到你自己挑的位置，因此應用程式**仍然不需要儲存權限**；還原會覆蓋目前資料，操作前會先顯示確認對話框。

**專注時鐘**是早期獨立的番茄鐘應用程式，保留給只需要計時器的使用者。

## 安裝限制

| 項目 | 要求 |
| --- | --- |
| **系統版本** | **Android 8.0（API 26）以上**。編譯目標為 Android 15（API 35） |
| **安裝檔大小** | 約 1.6 MB |
| **安裝方式** | 應用程式為自行簽章（未上架商店），需在系統設定中允許「安裝未知來源的應用程式」 |
| **要求權限** | 只有三項：通知、震動、開機後重新排程待辦提醒（重新啟動不會遺失提醒）。**不需要儲存權限**：備份與 CSV 檔案都透過系統檔案選擇器處理 |
| **網路** | **完全沒有網路權限**，不會把資料上傳到任何地方 |
| **資料存放** | 只存在本機。解除安裝會刪除資料；**覆蓋升級不會遺失資料**（資料庫自動遷移，目前為第 3 版） |
| **升級** | 所有版本套件名稱與簽章一致，可直接用新版 APK 覆蓋安裝舊版；升級時資料庫自動遷移，原有的記帳、待辦與專注紀錄完整保留 |
| **已知限制** | 只有正式版 APK 有簽章；測試版簽章不同，無法覆蓋安裝正式版。計時過程若被系統清除背景，計時會中斷。待辦提醒採用非精確鬧鐘（不申請精確鬧鐘權限），9:00 的通知可能晚幾分鐘 |
