# 日常本 DailyBook · 專注時鐘 FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

以 Kotlin + Jetpack Compose 撰寫的**純離線** Android 應用程式。
**沒有網路權限 —— 你的資料永遠不會離開手機。**

---

## 軟體介紹

**日常本**把三樣日常工具整合進一個應用程式：記帳、待辦、番茄鐘。
底部五個頁籤：**記帳 · 待辦 · 專注 · 統計 · 設定**。

| 頁籤 | 功能 |
| --- | --- |
| 📒 **記帳** | 支出 / 收入、預設分類、備註、日期選擇、**每一筆紀錄都歸屬某個帳戶（現金 / 微信 / 支付寶 / 銀行卡 / 其他，也可以自己輸入帳戶名稱），頂端有帳戶篩選膠囊、非現金的紀錄會顯示帳戶**、依月份分組的流水、月份切換、分類佔比、每日支出長條圖、**每月預算進度條（到 80% 與超支時各提醒一次）**、**每個分類各自設定每月預算（分類超支也會提醒）**、**搜尋**、**點任一筆紀錄即可編輯**、**每晚提醒記帳**、**匯出 CSV（Excel 開啟不亂碼）**、**多幣別：除了人民幣還能記美金 / 日圓 / 歐元 / 港幣 / 英鎊，選好幣別再填一個匯率，應用程式會存下換算後的人民幣金額，匯率按幣別記住，外幣紀錄會同時顯示原幣金額與換算金額（如 `$12.34 ≈ ¥87.61`）**、**標籤：一筆紀錄可以帶多個標籤（旅行 / 報帳 / 裝修……），記帳頁有標籤篩選列**、**待報帳：先把一筆標成待報帳，報帳入帳後再標成已報帳**、**自訂分類（設定 → 記帳 → 分類管理）：支出與收入分別增刪分類，一鍵就能恢復預設分類**、**匯入 CSV（也認應用程式自己匯出的檔案）** |
| ✅ **待辦** | 快速新增、完成勾選、標記重要、截止日與逾期標示、**重複任務（每天 / 每週 / 每月，完成後自動產生下一次）**、**到期提醒通知（點通知直接開啟應用程式，通知上還有「1 小時後」與「明天早上」兩個稍後提醒按鈕）**、**編輯視窗裡的「順延到明天」按鈕（一鍵把截止日推到明天）**、狀態篩選、**搜尋**、一鍵清除已完成 |
| ⏱️ **專注** | 番茄鐘：專注 / 短休息 / 長休息，圓環漸層進度，階段結束通知 + 震動，可選自動進入下一階段，每 N 個番茄安排長休息，**每日專注目標（1 / 2 / 3 / 4 / 6 / 8 或不定目標，晚上還沒達標會再提醒一次）**，**今日專注明細**、**正計時：想專注多久就多久，點「完成」把這段時間記成一次專注**、**中斷紀錄：番茄模式下中途停止或跳過專注階段，只要已過 1 分鐘也會記下來並標成「中斷」** |
| 📊 **統計** | 今日番茄數、連續專注天數、近 7 天長條圖、**近 12 週專注熱力圖（一欄一週，週一到週日，顏色越深代表當天專注越久）與本週次數 / 本週時長 / 本月時長 / 本月次數**、記帳彙總、**近 12 個月收支趨勢圖**、**年度彙總**（年支出 / 年收入 / 年結餘、筆數、花費最多的分類）、**帳戶支出分佈**、**分類預算進度條（超支標紅）**、**今日專注目標進度條**、**依待辦統計投入時間（只統計從該待辦發起的專注，取前 10 筆）**、**累計收支與淨結餘**、**待報帳卡片（待報帳合計金額與筆數，以及累計已報帳金額）**、**中斷的專注會標示出來** |
| ⚙️ **設定** | **介面語言（简体中文 / 繁體中文 / English / 日本語，四個膠囊，切換立即生效不用重新啟動）**、各階段時長、震動、螢幕恆亮、主題、**每日專注目標**、**分類預算管理**、**預算提醒開關**、**每晚記帳提醒與提醒時間**、**定期小結（關閉 / 每週 / 每月，每週日 20:00 或每月 1 日 10:00 發一則）**、**備份與還原**、**匯出 CSV**、**分類管理（增刪支出與收入分類，或一鍵恢復預設分類）**、**匯入 CSV**、資料清除 |

另外還有：帶顏色與 emoji 的分類徽章、**桌面捷徑（長按應用程式圖示可直接記一筆 / 加待辦 / 開始專注）**、平板 / 橫向的側邊導覽版面。

**四種語言**：所有介面、所有通知與匯出的 CSV 都支援 **简体中文 / 繁體中文 / English / 日本語**，在「設定 → 語言」切換，**立即生效，不用重新啟動**。桌面圖示名稱與長按捷徑的名稱跟隨**系統**語言，因為它們屬於系統介面，不是由應用程式自行繪製。

**備份與還原**：把全部資料（記帳及其帳戶、標籤、幣別與報帳狀態，待辦及其重複規則，專注紀錄，每月預算與分類預算）匯出成一個 JSON 檔案，之後可以整份還原，換手機或重裝都不必擔心。檔案透過系統檔案選擇器存到你自己挑的位置，因此應用程式**仍然不需要儲存權限**；還原會覆蓋目前資料，操作前會先顯示確認對話框。舊版本寫出的備份仍可正常還原，缺少的欄位會以預設值補上（標籤為空、不是待報帳、人民幣匯率 10000）。

**統一以人民幣統計**：雖然可以記外幣，但應用程式存下的是換算後的人民幣金額（原幣金額也一併保留、清單裡會顯示出來），所以**所有統計、預算與報表都統一在人民幣這一個基準上**。匯入也一樣謹慎：**匯入 CSV 時，與現有紀錄完全相同的列（日期、金額、類型、分類、帳戶、備註都一樣）會被略過**，同一個檔案匯入兩次也不會重複；讀不懂的列直接忽略，不會讓整次匯入失敗。

**專注時鐘**是早期獨立的番茄鐘應用程式，保留給只需要計時器的使用者。

## 安裝限制

| 項目 | 要求 |
| --- | --- |
| **系統版本** | **Android 8.0（API 26）以上**。編譯目標為 Android 15（API 35） |
| **安裝檔大小** | 約 1.7 MB |
| **安裝方式** | 應用程式為自行簽章（未上架商店），需在系統設定中允許「安裝未知來源的應用程式」 |
| **要求權限** | 只有三項：通知、震動、開機後重新排程提醒（重新啟動不會遺失待辦提醒、每晚記帳提醒與定期小結）。**不需要儲存權限**：備份與 CSV 檔案都透過系統檔案選擇器處理 |
| **網路** | **完全沒有網路權限**，不會把資料上傳到任何地方 |
| **資料存放** | 只存在本機。解除安裝會刪除資料；**覆蓋升級不會遺失資料**（資料庫自動遷移，目前為第 5 版），舊版本寫入的紀錄會取得安全的預設值（標籤為空、不是待報帳、人民幣匯率 10000） |
| **升級** | 所有版本套件名稱與簽章一致，可直接用新版 APK 覆蓋安裝舊版；升級時資料庫自動遷移，原有的記帳、待辦與專注紀錄完整保留。舊版本匯出的備份也仍可還原，缺少的欄位會以預設值補上 |
| **已知限制** | 只有正式版 APK 有簽章；測試版簽章不同，無法覆蓋安裝正式版。計時過程若被系統清除背景，計時會中斷。待辦提醒與每晚記帳提醒用的都是非精確鬧鐘（不申請精確鬧鐘權限），9:00 或 21:00 的通知可能晚幾分鐘。統計一律以人民幣為基準，外幣按你填的匯率換算。刪除分類不會動到既有紀錄，分類名稱仍留在那些紀錄上。專注不足 1 分鐘不會被記成中斷紀錄，休息階段更不會被記錄。應用程式內切換語言不會改變桌面圖示名稱與長按捷徑，它們跟隨系統語言 |
