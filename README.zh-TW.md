# 日常本 DailyBook · 專注時鐘 FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

以 Kotlin + Jetpack Compose 撰寫的**純離線** Android 應用程式。
**沒有網路權限 —— 你的資料永遠不會離開手機。**

---

## 軟體介紹

**日常本**把五樣日常工具整合進一個應用程式：記帳、生活、學習、待辦、番茄鐘。
底部五個頁籤：**記帳 · 生活 · 學習 · 專注 · 統計**；設定搬到了頂端列的齒輪圖示裡，二級頁面則在頂端列左側顯示返回箭頭。

| 頁籤 | 功能 |
| --- | --- |
| 📒 **記帳** | 支出 / 收入、預設分類、備註、日期選擇、**每一筆紀錄都歸屬某個帳戶（現金 / 微信 / 支付寶 / 銀行卡 / 其他，也可以自己輸入帳戶名稱），頂端有帳戶篩選膠囊、非現金的紀錄會顯示帳戶**、依月份分組的流水、月份切換、分類佔比、每日支出長條圖、**每月預算進度條（到 80% 與超支時各提醒一次）**、**每個分類各自設定每月預算（分類超支也會提醒）**、**搜尋**、**點任一筆紀錄即可編輯**、**每晚提醒記帳**、**匯出 CSV（Excel 開啟不亂碼）**、**多幣別：除了人民幣還能記美金 / 日圓 / 歐元 / 港幣 / 英鎊，選好幣別再填一個匯率，應用程式會存下換算後的人民幣金額，匯率按幣別記住，外幣紀錄會同時顯示原幣金額與換算金額（如 `$12.34 ≈ ¥87.61`）**、**標籤：一筆紀錄可以帶多個標籤（旅行 / 報帳 / 裝修……），記帳頁有標籤篩選列**、**待報帳：先把一筆標成待報帳，報帳入帳後再標成已報帳**、**自訂分類（設定 → 記帳 → 分類管理）：支出與收入分別增刪分類，一鍵就能恢復預設分類**、**匯入 CSV（也認應用程式自己匯出的檔案）** |
| ✅ **待辦** | 快速新增、完成勾選、標記重要、截止日與逾期標示、**子任務：一則待辦可以帶一份小步驟清單，在編輯視窗裡勾選、刪除、新增，清單列會顯示進度（如 `2/5`）與一條細進度條；刪掉待辦時它的子任務一併刪除，不留孤兒資料**、**優先級四級（低 / 普通 / 高 / 緊急）：視窗裡能設定，清單列上也能直接改，列上帶標記（普通不標記），舊待辦預設為「普通」**、**拖曳排序：長按待辦拖動即可重排，新順序會被儲存，單擊仍然是開啟編輯；搜尋中、已完成篩選與看板檢視下不支援排序（介面會直接說明，而不是默默沒反應）**、**清單 / 看板檢視切換：看板把同一批待辦按「今天到期 / 本週內 / 以後 / 沒有日期 / 已完成」分組並顯示各組筆數，空的分組不顯示**、**重複任務（每天 / 每週 / 每月，完成後自動產生下一次）**、**到期提醒通知（點通知直接開啟應用程式，通知上還有「1 小時後」與「明天早上」兩個稍後提醒按鈕）**、**編輯視窗裡的「順延到明天」按鈕（一鍵把截止日推到明天）**、狀態篩選、**搜尋**、一鍵清除已完成 |
| ⏱️ **專注** | 番茄鐘：專注 / 短休息 / 長休息，圓環漸層進度，階段結束通知 + 震動，可選自動進入下一階段，每 N 個番茄安排長休息，**每日專注目標（1 / 2 / 3 / 4 / 6 / 8 或不定目標，晚上還沒達標會再提醒一次）**，**今日專注明細**、**正計時：想專注多久就多久，點「完成」把這段時間記成一次專注**、**中斷紀錄：番茄模式下中途停止或跳過專注階段，只要已過 1 分鐘也會記下來並標成「中斷」** |
| 📊 **統計** | 今日番茄數、連續專注天數、近 7 天長條圖、**近 12 週專注熱力圖（一欄一週，週一到週日，顏色越深代表當天專注越久）與本週次數 / 本週時長 / 本月時長 / 本月次數**、記帳彙總、**近 12 個月收支趨勢圖**、**年度彙總**（年支出 / 年收入 / 年結餘、筆數、花費最多的分類）、**帳戶支出分佈**、**分類預算進度條（超支標紅）**、**今日專注目標進度條**、**依待辦統計投入時間（只統計從該待辦發起的專注，取前 10 筆）**、**累計收支與淨結餘**、**待報帳卡片（待報帳合計金額與筆數，以及累計已報帳金額）**、**環比對比（本月 vs 上月看支出與收入、今年 vs 去年看支出，給出帶正負號的百分比；沒有可比基準時——例如上個月一筆紀錄都沒有——會直接說明兩筆金額無法比較，而不是編一個 0% 或 +100%）**、**智慧洞察（最多四條白話觀察：比上個月多花 / 少花了多少、以及是哪個分類拉動的，本月花得最多的分類，距上一次記帳過了多少天，預算還剩多少；本月完全沒有資料時一條都不顯示）**、**月報匯出（把本月匯出成一張可分享的 PNG 圖片、一個獨立 HTML 檔案（只用內嵌 CSS，不含腳本、不引用任何外部資源，離線也能正常閱讀）和一份 PDF（A4，頁數依內容自動增加）；三種都走系統檔案選擇器，所以應用程式依然不需要儲存權限；月報裡有當月的數字、長條圖、分類組成、專注統計與洞察文字；本月還沒有資料時會提示沒有可匯出的內容，而不是寫一個空檔案）**、**年 / 月快速切換列（◀ ▶ 加一個可點的中間區域，點開是「年 + 12 個月」選擇器，附「回到本月」，換月份一下到位，不用點很多下；記帳頁也有同一條）**、**原本的原始明細清單改成標題列：「本月紀錄 / 分類明細 / 每日明細 / 專注紀錄 / 待辦完成情況」各自開啟獨立詳情頁，所有彙總卡、圖表、環比、洞察與月報匯出都留在統計頁上**、**中斷的專注會標示出來** |
| 🧺 **生活** | 一條分段控制項切換五個檢視：**待辦 / 習慣打卡 / 備忘錄 / 大事記 / 重要日期**。**習慣打卡：每個習慣一列，帶 emoji、名稱、今天的進度（目標 + 單位，如次 / 個 / 頁 / 分鐘）、目前連續天數（連續 N 天）、本週打卡幾天、7 天小格，用 +/− 記數、點整列也能打卡；新增 / 編輯視窗裡有 emoji、目標、單位與每週目標——背單字 / 背書計畫用的就是同一套機制，也就是一個帶單位與每日目標的習慣，不另做功能**。**備忘錄：兩欄卡片，標題加一句預覽，可置頂 / 取消置頂、編輯、刪除**。**大事記：依年份分組的縱向時間軸，帶一條導軌（圓點 + 連接線）、標題、日期與備註；有附圖時會顯示提示，但不渲染圖片**。**重要日期：最上面一張大卡片倒數最近的一個（N 天 / 就是今天），其餘以列呈現；每一筆可以是陽曆或農曆（支援閏月），有重複規則（只過一次 / 每年 / 每月 / 每週）與可選提醒（提前 0 / 1 / 3 / 7 天），每一筆還能匯出 .ics——寫出真正的 RFC 5545 VEVENT（含 RRULE 與可選 VALARM），走系統檔案選擇器，匯入手機行事曆即可** |
| 🎓 **學習** | 一個入口頁：摘要卡（今天 / 本週幾堂課、GPA、下一場考試倒數、未完成與逾期的作業）、今天的課程直接列在下面，再加一格一格進入八個子頁面的卡片。**課表：今天 / 整週兩種檢視，一張 7 天 × 12 節的週表，課程區塊依節次區間佔高度、顏色來自固定調色盤；一門課帶星期、起止節、週次表達式（支援 `1-16`、`1,3,5-9` 與 `1-16单` 這類單雙週）、學期起始日與顏色**。**考試與複習：卡片依日期排序，帶一個大倒數（N 天 / 今天 / 已結束），展開就是這場考試的複習任務清單（勾選、刪除、就地新增），還有一個「自動排複習計畫」按鈕，依均勻間隔給出一份建議——介面上寫明這只是建議，可以自己刪**。**作業與 DDL：這就是待辦清單裡帶了課程名稱的那部分，依逾期 / 今天 / 本週 / 以後 / 沒有日期 / 已完成分組，逾期列高亮；新增一筆要填標題、課程與截止日**。**成績與 GPA：成績依學期分組，顯示分數、學分、換算後的績點與類別；新增 / 編輯視窗支援百分制 / 五級制 / 直接給績點，百分制依一份寫明的 4.0 分段換算，選了 5.0 口徑就等比放大**。**學分進度：依類別顯示已修 / 要求的進度條、一個總進度，還有一張「其他已修學分」卡片用來記沒有設目標的類別**。**獎助與證書：獎學金 / 競賽 / 證書 / 其他依類別分組，每一筆帶級別（國家級 / 省級 / 校級 / 院級）、日期與備註；有附圖同樣只給提示、不渲染圖片**。**學習週報：一份唯讀的最近 7 天小結（專注分鐘與次數、待辦完成、背單字打卡、支出、逾期作業），點「匯出圖片」把它畫成 PNG 走系統檔案選擇器儲存；待辦那一項是「目前已完成的總筆數」，因為資料庫沒有存完成日期** |
| ⚙️ **設定** | **改成系統設定那樣的表列：7 個分類——外觀 / 語言 / 記帳 / 專注 / 學習 / 資料與備份 / 關於與更新，每個點進去是獨立子頁面，原本所有設定項目都沒變、只是搬進對應分類**。**學習分類：學期起始日（日期選擇器，用來把課表的週次換成真實日期）、GPA 計算口徑（4.0 / 5.0）、上課提醒（暫時還不能排：課表只記節次、沒有具體時間，頁面上寫明了原因）**。**關於頁：應用程式名稱、套件名稱、版本號與最低 Android 版本都是執行時從已安裝的套件讀出來的（刻意不寫死），並說明資料都存在本機、附授權說明；檢查更新頁顯示目前版本並用瀏覽器開啟 GitHub releases 頁（`ACTION_VIEW`）——應用程式沒有網路權限，所以做不了應用程式內檢查更新，頁面上就是這樣如實寫的**。**介面語言（简体中文 / 繁體中文 / English / 日本語，四個膠囊，切換立即生效不用重新啟動）**、各階段時長、震動、螢幕恆亮、主題、**十二套配色（青（預設）/ 靛藍 / 紫羅蘭 / 玫紅 / 琥珀 / 森林 / 天藍 / 薄荷 / 珊瑚 / 咖啡 / 石墨 / 櫻花），每套都能用在淺色與深色模式下，而且每一套的對比度都是算出來的——正文 ≥ 4.5:1、控制項 ≥ 3:1，並驗過十二個主色互不相同——不會出現某個配色在深色下看不清的情況；跟隨系統取色開啟時依然優先於所選配色**、**自訂背景圖（用系統檔案選擇器挑任意一張圖，解碼走兩趟取樣，再大的照片也不會把記憶體吃光；換好之後各層表面變半透明，用遮罩滑桿（0~80）決定圖片透出多少，還有一個「清除」按鈕把它移除；解碼失敗按「沒有背景」處理，不會當掉）**、**每日專注目標**、**分類預算管理**、**預算提醒開關**、**每晚記帳提醒與提醒時間**、**週期記帳 / 固定支出（房租、訂閱這類固定支出設定一次就好：填金額、類型、分類、帳戶、備註、每週或每月的規則與首次到期日；到期時會自動補記——打開應用程式時補，或者到了晚上提醒的時間補，每補一次就把下次日期往後推，所以既不會漏也不會重複記，很久沒打開也只會補最近的一期，不會一次灌滿整本帳；每條規則可以暫停 / 恢復 / 刪除，設定裡那一列會顯示目前有幾條規則、下一條什麼時候到期）**、**定期小結（關閉 / 每週 / 每月，每週日 20:00 或每月 1 日 10:00 發一則）**、**備份與還原**、**自動備份（用系統檔案選擇器挑一個資料夾，應用程式在開啟時或晚上提醒時把全部資料寫成一個 JSON 檔案；一天最多一份，同一天覆寫而不會多出一個副本，只保留最新的 7 份、更舊的自動清理；清理時只刪自己產生的檔案（`DailyBook-backup-` 前綴），你放在同一個資料夾裡的其他檔案一律不碰；失敗會按原因如實說明（沒有權限 / 建不了檔案 / 寫不進去），失敗絕不會覆寫「上次成功備份」的紀錄，也絕不會顯示成成功）**、**匯出 CSV**、**分類管理（增刪支出與收入分類，或一鍵恢復預設分類）**、**匯入 CSV**、資料清除 |

另外還有：帶顏色與 emoji 的分類徽章、**桌面捷徑（長按應用程式圖示可直接記一筆 / 加待辦 / 開始專注）**、平板 / 橫向的側邊導覽版面。

**桌面小工具**：第一個顯示今天的支出與收入、還剩幾件待辦、今天專注了多少分鐘，點一下就開啟應用程式。第二個是**考試倒數**：顯示一場考試的名稱、日期與倒數（N 天 / 今天 / 已結束），加上課程名稱與地點，還有一個小小的「切換」熱區在接下來幾場考試之間輪換，記住的是這個實例自己的選擇；沒有待考的考試時給一句友善提示。兩個都用系統框架自帶的 `RemoteViews`（不是 Glance），在應用程式資料變動時重新整理，其餘時候按系統允許的最小間隔 30 分鐘重新整理一次；文字跟隨**系統**語言，系統認識應用程式內選的語言時會用應用程式內的語言。

**生活都在一個頁籤裡**：生活頁用一條分段控制項在待辦、習慣打卡、備忘錄、大事記、重要日期之間切換。習慣就是一列：emoji、名稱、帶單位的每日目標、目前連續天數、本週完成幾天與 7 天小格，用 +/− 或點整列記一次；**背單字 / 背書計畫不用另做功能，它就是一個帶單位與每日目標的習慣**。備忘錄是兩欄卡片。大事記是依年份分組的時間軸。重要日期最上面是最近那一筆的倒數卡片，並同時支援陽曆與**農曆**（含閏月）、重複規則、提醒，以及每一筆**匯出 .ics**，匯入手機行事曆即可。

**學習也都在一個頁籤裡**：學習頁是入口頁——摘要卡、今天的課程，再進八個子頁面（課表、考試與複習、作業與 DDL、成績與 GPA、學分進度、獎助與證書、學習週報，以及背單字計畫）。課表是 7 × 12 的週表，課程區塊依節次區間佔位、依課程取色，由 `1-16` 或 `1-16单` 這樣的週次表達式驅動。作業就是待辦清單裡帶課程名稱的那部分，依逾期 / 今天 / 本週 / 以後 / 沒有日期 / 已完成分組、逾期列高亮——是同一批列，不是第二份清單。考試展開就是複習任務清單，還有一個按鈕給出一份可以自己刪掉的均勻複習計畫。成績把百分制 / 五級制換成績點，週報把最近 7 天彙總成一張可以匯出成 PNG 的圖。

**關於與更新**：關於頁的名稱、套件名稱、版本號與最低 Android 版本都是執行時從已安裝的套件讀出來的，不寫死，並寫明資料都在本機。**檢查更新**只顯示目前版本，然後交給瀏覽器開啟 GitHub releases 頁——應用程式沒有網路權限，應用程式內檢查更新根本做不到，頁面上就是這樣寫的，不裝作能查。

**十二套配色**：青 / 靛藍 / 紫羅蘭 / 玫紅 / 琥珀 / 森林 / 天藍 / 薄荷 / 珊瑚 / 咖啡 / 石墨 / 櫻花，每套都有淺色與深色兩版。對比度不是靠眼睛看，而是算出來的：單元測試逐個算 WCAG 對比度，要求兩種模式下正文 ≥ 4.5:1、控制項 ≥ 3:1，並且十二個主色互不相同——所以哪個配色接錯了、切了沒變化，都逃不過建置。還可以設**自訂背景圖**：用系統檔案選擇器挑一張圖，各層表面變半透明，遮罩滑桿（0~80）決定圖片透出多少，另有「清除」按鈕把它移除。

**四種語言**：所有介面、所有通知與匯出的 CSV 都支援 **简体中文 / 繁體中文 / English / 日本語**，在「設定 → 語言」切換，**立即生效，不用重新啟動**。桌面圖示名稱與長按捷徑的名稱跟隨**系統**語言，因為它們屬於系統介面，不是由應用程式自行繪製。

**備份與還原**：把全部資料（記帳及其帳戶、標籤、幣別與報帳狀態，待辦及其子任務清單、優先級、手動順序與課程名稱，週期記帳規則，專注紀錄，每月預算與分類預算，以及生活紀錄——備忘錄、大事記、重要日期、習慣與打卡紀錄——和學習紀錄——課程、考試與複習任務、成績、學分目標、獎助與證書）匯出成一個 JSON 檔案，之後可以整份還原，換手機或重裝都不必擔心。檔案透過系統檔案選擇器存到你自己挑的位置，因此應用程式**仍然不需要儲存權限**；還原會覆蓋目前資料，操作前會先顯示確認對話框。舊版本寫出的備份仍可正常還原——v2~v4 的舊備份也認，沒有的那幾段就是空的，缺少的欄位會以預設值補上（標籤為空、不是待報帳、人民幣匯率 10000、優先級是「普通」、沒有子任務）。

**自動備份**：用**系統檔案選擇器**挑一個資料夾，所以**仍然不需要儲存權限**；應用程式在開啟時、或者到了晚上提醒的時間，把全部資料寫成一個 JSON 檔案。**一天最多一份**（同一天覆寫，不會多出一個 `…… (1).json` 這樣的副本），並且**只保留最新的 7 份**、更舊的自動清理；清理時**只刪自己產生的檔案**（`DailyBook-backup-` 前綴），你放在同一個資料夾裡的其他東西一律不碰。失敗會按原因如實說明（沒有權限 / 建不了檔案 / 寫不進去），而不是假裝成功：**失敗絕不會覆寫「上次成功備份」的紀錄，也絕不會顯示成成功**。

**統一以人民幣統計**：雖然可以記外幣，但應用程式存下的是換算後的人民幣金額（原幣金額也一併保留、清單裡會顯示出來），所以**所有統計、預算與報表都統一在人民幣這一個基準上**。匯入也一樣謹慎：**匯入 CSV 時，與現有紀錄完全相同的列（日期、金額、類型、分類、帳戶、備註都一樣）會被略過**，同一個檔案匯入兩次也不會重複；讀不懂的列直接忽略，不會讓整次匯入失敗。

**固定支出自動補記**：週期記帳的到期紀錄是**打開應用程式時補**的（或者到了每晚提醒的時間補），每補一次就把該規則的下次到期日往後推，所以**既不會漏記也不會記兩遍**；隔了很久才打開，也只會補最近的一期，不會一口氣把中間落下的幾期全寫進帳本。

**月報匯出**：統計頁可以把本月匯出成一張**可分享的 PNG 圖片**、一個**獨立 HTML 檔案**（只用內嵌 CSS，不含腳本、不引用任何外部資源，離線也能正常閱讀）和一份 **PDF**（A4，頁數依內容自動增加）。三種都經系統檔案選擇器儲存，所以應用程式**仍然不需要儲存權限**；月報裡包含當月的數字、長條圖、分類組成、專注統計與洞察文字，本月還沒有資料時會直接提示沒有可匯出的內容，而不是寫一個空檔案。

**專注時鐘**是早期獨立的番茄鐘應用程式，保留給只需要計時器的使用者。

## 安裝限制

| 項目 | 要求 |
| --- | --- |
| **系統版本** | **Android 8.0（API 26）以上**。編譯目標為 Android 15（API 35） |
| **安裝檔大小** | 約 2 MB |
| **安裝方式** | 應用程式為自行簽章（未上架商店），需在系統設定中允許「安裝未知來源的應用程式」 |
| **要求權限** | 只有三項：通知、震動、開機後重新排程提醒（重新啟動不會遺失待辦提醒、每晚記帳提醒與定期小結）。**不需要儲存權限**：備份、CSV 檔案、月報、匯出 .ics 與週報 PNG 都透過系統檔案選擇器處理。**v1.9 一個權限都沒加**：第二個小工具用的是框架自帶的 `RemoteViews`，背景圖與 .ics / PNG 匯出都走系統檔案選擇器，檢查更新只是開啟瀏覽器 |
| **網路** | **完全沒有網路權限**，不會把資料上傳到任何地方。所以「檢查更新」也查不了任何東西：它只顯示你目前的版本，把發佈頁交給瀏覽器 |
| **資料存放** | 只存在本機。解除安裝會刪除資料；**覆蓋升級不會遺失資料**（資料庫自動遷移，目前為第 7 版：`todos` 多了 `courseName`，並新增 11 張表——備忘錄、大事記、重要日期、習慣、習慣打卡、課程、考試、複習任務、成績、學分目標、獎助與證書），舊版本寫入的紀錄會取得安全的預設值（標籤為空、不是待報帳、人民幣匯率 10000、優先級是「普通」、沒有子任務、沒有課程名稱） |
| **升級** | 所有版本套件名稱與簽章一致，可直接用新版 APK 覆蓋安裝舊版；升級時資料庫自動遷移，原有的記帳、待辦與專注紀錄完整保留。舊版本匯出的備份也仍可還原——v2~v4 的舊備份也認，沒有的段就當空的，缺少的欄位會以預設值補上 |
| **已知限制** | 只有正式版 APK 有簽章；測試版簽章不同，無法覆蓋安裝正式版。計時過程若被系統清除背景，計時會中斷。待辦提醒與每晚記帳提醒用的都是非精確鬧鐘（不申請精確鬧鐘權限），9:00 或 21:00 的通知可能晚幾分鐘。統計一律以人民幣為基準，外幣按你填的匯率換算。刪除分類不會動到既有紀錄，分類名稱仍留在那些紀錄上。專注不足 1 分鐘不會被記成中斷紀錄，休息階段更不會被記錄。應用程式內切換語言不會改變桌面圖示名稱與長按捷徑，它們跟隨系統語言。待辦的拖曳排序只在一般清單裡可用：搜尋中、已完成篩選與看板檢視下，應用程式會直接說明不支援排序。週期記帳不是背景定時寫入，而是在打開應用程式或每晚提醒時補記，所以到期的紀錄要等下次打開應用程式才落到帳本上，很久沒打開也只補最近的一期。今日小工具只顯示當天的數字，倒數小工具一次只顯示一場考試。大事記與獎助裡附的圖片只給提示、不渲染（沒有打包圖片庫），週報裡的待辦項是「目前已完成的總筆數」，因為資料庫沒有存完成日期。作業與 DDL 就是待辦清單依課程名稱篩出來的，背單字計畫就是一個習慣，都不是單獨的表格。統計頁與記帳頁都跟著你選取的月份走，所以數字看著不對時先看看月份。**這一版（v1.9）移除了應用程式鎖**：沒有密碼畫面、沒有指紋 / 臉部辨識這條路徑，資料也不做任何加密——那個鎖只存在於 v1.8，已按要求整條移除。自動備份只在打開應用程式或每日鬧鐘響的時候做，所以一直不打開應用程式就不會有新的備份；寫出的 JSON 是明文，放在你自己挑的資料夾裡，那個資料夾可能是雲端同步空間 |
