# 日常本 DailyBook · 專注時鐘 FocusFlow

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md)

以 Kotlin + Jetpack Compose 撰寫的**純離線** Android 應用程式。
**沒有網路權限 —— 你的資料永遠不會離開手機。**

---

## 軟體介紹

**日常本**把三樣日常工具整合進一個應用程式：記帳、待辦、番茄鐘。
底部五個頁籤：**記帳 · 待辦 · 專注 · 統計 · 設定**。

| 頁籤 | 功能 |
| --- | --- |
| 📒 **記帳** | 支出 / 收入、預設分類、備註、日期選擇、依月份分組的流水、月份切換、分類佔比、每日支出長條圖、**每月預算進度條**、**搜尋**、**點任一筆紀錄即可編輯** |
| ✅ **待辦** | 快速新增、完成勾選、標記重要、截止日與逾期標示、狀態篩選、**搜尋**、一鍵清除已完成 |
| ⏱️ **專注** | 番茄鐘：專注 / 短休息 / 長休息，圓環漸層進度，階段結束通知 + 震動，可選自動進入下一階段，每 N 個番茄安排長休息，**今日專注明細** |
| 📊 **統計** | 今日番茄數、連續專注天數、近 7 天長條圖、記帳彙總 |
| ⚙️ **設定** | 各階段時長、震動、螢幕恆亮、主題、資料清除 |

另外還有：帶顏色與 emoji 的分類徽章、平板 / 橫向的側邊導覽版面、中英文介面。

**專注時鐘**是早期獨立的番茄鐘應用程式，保留給只需要計時器的使用者。

## 安裝限制

| 項目 | 要求 |
| --- | --- |
| **系統版本** | **Android 8.0（API 26）以上**。編譯目標為 Android 15（API 35） |
| **安裝檔大小** | 約 1.6 MB |
| **安裝方式** | 應用程式為自行簽章（未上架商店），需在系統設定中允許「安裝未知來源的應用程式」 |
| **要求權限** | 只有兩項：通知、震動 |
| **網路** | **完全沒有網路權限**，不會把資料上傳到任何地方 |
| **資料存放** | 只存在本機。解除安裝會刪除資料；**覆蓋升級不會遺失資料**（資料庫自動遷移） |
| **升級** | 所有版本套件名稱與簽章一致，可直接用新版 APK 覆蓋安裝舊版 |
| **已知限制** | 只有正式版 APK 有簽章；測試版簽章不同，無法覆蓋安裝正式版。計時過程若被系統清除背景，計時會中斷 |
